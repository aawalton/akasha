Spiking a dungeon beyond level five hundred works essentially the same as any dungeon you’ve run before, with the spike working the same and the instance overcharging the same, but the normal spikes just don’t make as big a dent in the mana pool the dungeon has stored as they would have. If a dungeon below five hundred has a hundred mana, just for example, and a regular run takes two mana, while a spike takes ten, then a dungeon at or beyond five hundred has five thousand mana. The run of an instance, and the spike, would be the same numbers, but you are now dealing with a mana pool thirty, forty, or fifty times the size that you’re used to.”
