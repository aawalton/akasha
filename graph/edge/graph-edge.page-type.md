# Definition

- **Graph edge** — one link from one node to another.

# Design

A node kind on a graph-edge page is a list.

# Condition

An edge runs from the node that names another to the one it names.

# Rules

## Name The Artifact

**Mark an edge as deriving only where a program recomputes one end from the other.**

A reference that matters to a reader reads exactly like one a program recomputes from.

Name the artifact, or the answer is none.

A check going red is not an answer going stale.
