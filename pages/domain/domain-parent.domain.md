# Definition

- **Domain parent** — the one domain a domain sits inside.

# Design

Every domain names one parent, and `global` names itself.

A domain's parent is required reading for it.

A domain needed only to read this one is named as required reading, not made its parent.

A layer a domain is built on is not a parent of it.

A page type extending `domain` is not a reason for `domain` to be a parent.
