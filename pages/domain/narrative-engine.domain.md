# Definition

- **Narrative engine** — worlds and their stories, kept true to each other.

# Design

A player's message wrapped whole in square brackets is him speaking to the game master rather than acting in the world.

# Intent

No deployed code names one story or one world.

Every word a game master is served changes without a deploy.

No part of a story or a world exists only in the database.

Every kind of thing the narrative engine keeps in the database has a domain that defines it and a file that carries it.

Everything in `stories/dirty` has been resolved.
