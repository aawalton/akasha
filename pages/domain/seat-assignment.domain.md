# Definition

- **Seat assignment** — what a seat has been handed: `on-call` or `dispatch`.

# Design

A seat can carry more than one assignment at once.

An assignment is set and changed only by its principal; where that is Alan, the seat writes it at his direction.

An assignment ends when the work it names is done and whoever acts next has been told.

Every assignment is stated on the seat.

# Intent

An assignment that has ended is no longer stated on the seat.
