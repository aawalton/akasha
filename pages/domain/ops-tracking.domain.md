# Definition

- **Ops tracking** — the commands that record Alan's day as named sessions and rewrite the figures that day is scored on.

# Design

A command that opens a session refuses while one is already open, so the day is a single unbroken chain.

A title no activity in the catalog matches is refused rather than written unrated.

The hourly question is gated on the ledger alone, and an answer nobody has stamped as applied stops the next one.
