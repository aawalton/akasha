# Definition

- **Seat assignment errand** — work a principal hands a seat that no task or initiative names.

# Design

The prompt a seat was started with stands on the seat as its errand, until its principal states another.

Nothing observable ends an errand, so no sweep counts one as an assignment a seat still holds.
