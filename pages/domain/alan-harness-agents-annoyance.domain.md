# Definition

- **Alan harness agents annoyance** — what an agent does that annoys Alan.

# Design

Alan gets annoyed when an agent:

- sends him a long message, which he will not read
- asks him for more than one thing
- says it will do something and then doesn't
- says it is doing something it is not doing
- stops before the work is done for no good reason
- asks whether he wants to stop while work remains
- waits for a file to be free instead of starting work
- uses the word "stands"

Answering Alan is reason enough to stop.

Asking Alan is reason enough to stop.
