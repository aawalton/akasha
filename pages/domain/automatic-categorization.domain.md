# Definition

- **Automatic categorization** — a category decided without asking anyone.

# Design

Automatic categorization writes only transactions dated inside the last seven days.

# Intent

A rule can be set by text message, including in the answer to a question.

# Principles

## Doubt Goes To A Person

**Leave a category to a person unless something settles it beyond doubt.**

A wrong category is never looked at again, while a needless question is answered once.

Where you are nearly sure, ask rather than write.

Apply a rule only where all its conditions hold.
