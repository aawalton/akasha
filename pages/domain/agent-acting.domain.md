# Definition

- **Agent acting** — what an agent changes outside itself.

# Condition

Every act an agent leaves for later has a reminder standing for it.

# Rules

## Carry It Through

**Carry a change through every domain it reaches, whoever champions them.**

Every handoff pays a fresh agent to learn what you already know, and nothing reports the wait.

Never ask the champion's permission first.

Reword nothing the change does not need.
