# Definition

- **Royal Road** — the serial fiction site Alan reads from.

# Design

The file tree says which stories to sync.

Reading a chapter while signed in marks it read on Royal Road.

A chapter is fetched without the account.

A `<br>` adds no whitespace to a chapter's prose.

# Intent

A story Alan newly follows on Royal Road reaches the file tree without him adding it.

A chapter read here is marked read on Royal Road.
