# Definition

- **Repetition** — one thing expressed the same way everywhere it appears.

# Principles

## Same Kind Same Way

**Show a thing the way its kind is already shown.**

A reader learns a kind once and knows it everywhere, until a second way makes them learn it twice.

Follow a kind exactly, or add one where none fits.

Take the kind from all instances, not the nearest.

# Rules

## Standardized Palette

**Reference a design-system token; never write the value it resolves to.**

A literal value is right the moment you write it, and stays behind silently when the palette moves.

Pick the token whose meaning fits, or add one.

Build a new value from the token, not its number.
