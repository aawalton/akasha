# Definition

- **Read record** — what each agent has read, when, and how much of it.

# Design

A record covers the lines a reader saw, never the file they opened.

An authored change discards what was read of the body.

A read that names no range covers only what the tool returned.

A replaced context takes every reading the agent has made.

A body standing in the system prompt survives that replacement.

The read record is runtime state, committed to no repository.

A read the system did not perform leaves no record.

# Condition

A mechanical change leaves the body read for every gate asking what its writer read.

A record names the body read, and separately the body a mechanical change has left.
