# Definition

- **Language evolution** — how a language changes once programs are written in it.

# Principles

## Rewrite Rather Than Widen

**Change the programs with the language wherever they are all yours.**

Syntax kept so old programs still run is power the language keeps forever and never needed.

Find every program before you change a meaning.

Never add syntax to spare yourself a rewrite.
