# Definition

- **Required reading** — what an agent must have read before an act is allowed.

# Design

Required reading is a declared reading and everything that set names in turn, read or written.

Required reading reaches an agent only through a read it runs itself.

A document may require one that requires it back.

Nothing outside akasha asks an agent what it has read.

A seat refused for an unread document may read and search, and nothing else.

Where nothing identifies the agent, a seat is allowed to act and an akasha write is refused.

# Intent

A reading a seat owes for an akasha act arrives as a refusal of that act, never as a message.

# Rules

## Route Not Text

**Name the reading and the route that records it; never hand the agent the text.**

Handed text is disbelieved or truncated, and the record then shows a reading that never happened.

Send neither the text nor a stand-in for it.

A line quoted to point at work is not the text.
