# Definition

- **Sleep** — the rest Alan has to work for.

# Design

Sleep is attributed by the block's link to a day, never by a clock.

A block counts as sleep by a word in its title, matched at word boundaries.

A day with a row and no linked block reads zero, which is not the same as never measured.
