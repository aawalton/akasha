# Definition

- **Context warrant file** — what a seat must read for the file it has in hand.

# Design

A file warrants itself.

A file warrants the repo it stands in.

A file warrants every domain whose glob matches it.

A page warrants its page type and every type that one extends.

A file warrants only for the seat changing it, not for one reading it.

Nothing a page type names in turn is required for the pages it types.

A file warrants no domain's parent.
