# Definition

- **Domain championing** — one persona answering for one domain.

# Design

Every domain has exactly one champion, and every champion exactly one domain.

A domain naming a persona is championed by her rather than by whoever champions the one above it.

A champion answers for a domain; any agent may change it without asking her.

Championing descends the parent tree from wherever a persona is named.
