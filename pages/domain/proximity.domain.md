# Definition

- **Proximity** — how near things are placed to each other.

# Principles

## Nothing Nearer

**Let nothing sit nearer a thing than what it belongs with.**

Distance is read before anything else, so a wrong gap beats any border or label you add to fix it.

Judge the gaps on the render, not in the code.

Widen the gap between groups, not every gap.
