# Definition

- **Seat name** — the address composed from what a seat states.

# Design

A seat's name spells no on-call assignment.

A seat's name, its terminal tab name and its Remote Control session title are one value.

A seat name is never ambiguous: where more than one set of stated values would spell it, the narrower reading wins.

A seat name reaches the seat that carried it most recently.

A seat whose principal is Alan takes its persona's name alone, unless that persona is the default.

Every other seat's name spells everything it states except its persona.

A handler's seat spells the person it serves, and nothing else.
