# Definition

- **Language syntax** — how a program is written and how it is read.

# Principles

## Reads As It Looks

**Make a program mean what its reader would take it to mean.**

Nothing checks a reading against the grammar, so looking at the program is the only check most get.

Take the reading a stranger would give it.

Never let a spelling suggest the wrong meaning.
