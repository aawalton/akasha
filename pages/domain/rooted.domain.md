# Definition

- **Rooted** — a node a deploy root reaches.

# Design

A node is rooted because of the edges that reach it.

A node takes rooting edges whatever it stands for.

Rooted is not used, and unrooted is not unused: the rule reads a deploy's reach and nothing else.
