# Definition

- **Caching** — keeping a result rather than working it out again.

# Intent

A cache gives back an answer only while everything that went into it is unchanged.

Every cache key is taken from what its inputs hold, never from when they changed.

Deleting a cache changes only how long its answer takes.

A cache goes when what it was taken from goes.
