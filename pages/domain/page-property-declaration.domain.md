# Definition

- **Page property declaration** — a property definition attaching to a page type.

# Design

A property definition's own page type and the one it defines a property on are different.

A page type names no property definition declared on it.

A property definition's domain is named for the type it is declared on and the key it states.

A page type may declare a key it already inherits. Both declarations stand, and the new one names which it narrows.
