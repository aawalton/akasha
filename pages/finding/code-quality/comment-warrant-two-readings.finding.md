# Claim

The warrant under Code Comments in `domains/code-quality.md` reads two ways. It ends "so a note here rots unseen by any reader of the instructions tree". `here` is meant as *in the code*, but the nearer noun is the instructions tree, which is also the tree the reader is holding. One reading says a note in code is invisible to a reader of instructions; the other says a note in instructions is invisible there. The two ask for different things.

# Evidence

Raised by `claude-code-quality-archivist-review-instructions` during a review-instructions reading of `domains/code-quality.md` on 2026-08-09, and left standing rather than landed: Every Changed Line on `domains/domain.md` holds a Rules line for Alan, and nothing in that seat's dispatch released it. The wording it proposed was "so a note in the code rots unseen by any reader of the instructions tree".

The filing seat confirmed the line reads as quoted at `domains/code-quality.md` line 19. Not measured: whether any reader has taken the wrong sense, and whether the proposed wording is the one Alan would pick.
