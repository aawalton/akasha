# Claim

Project #17548 (domain `code-editor`), captured 2026-08-02 by `amy-lead` from the code-editor vision interview, observes that `domains/code-editor.md`'s clause letting any agent arrange the editor's chrome for a kind of change Alan already approved "as a category" has no durable record of any approved category, so every agent asks every time — the outcome the clause exists to prevent — and is parked, not urgent, since no agent yet reaches the chrome and #17537 is its prerequisite phase.

# Evidence

Project #17548, domain `code-editor`. Captured by `amy-lead` from the code-editor vision interview, 2026-08-02. Parked, not started: it depends on the editor existing, and #17537 is its prerequisite phase.

`domains/code-editor.md` holds the clause this row exists to make true: "Any of them may, rather than one seat the rest go through — but only where Alan asked for it, or where he has already approved that kind of change; a kind not yet approved is asked for once and stands afterwards."

Alan's words that produced it: "Any agent may do, we can implement reasonable safeguards in the tooling and surround instructions" and "Agents should only change the chrome when I ask them to or in specific cases that I previously approved as a category (as they come up)."

**The gap.** Nothing anywhere records an approved category. The clause has two halves and only one is buildable today: "asked for once" is a message to Alan, which exists; "stands afterwards" is a read of a durable record, which does not. Without the second half every agent asks every time, the outcome the clause was written to prevent, and Alan pays for it in the currency the whole system is most careful with.

**Undecided.** What a category is and how coarsely drawn — "may open a panel" versus "may change my layout" is the gap between a useful standing approval and a blank cheque. Where the record lives, given the readers are agents and the author is Alan. Whether an approval can be narrowed or withdrawn, and what happens when the chrome it named changes shape. Whether an agent misreading its scope is caught by the record or by something else.

**Why not urgent.** No agent reaches the chrome yet. The row becomes real the moment one can, and should be settled before rather than after: the first agent arranging something Alan did not ask for is the case this exists to prevent, not learn from.

Captured and never defined: it carries no objective, and one written now would be a definition act nobody performed.
