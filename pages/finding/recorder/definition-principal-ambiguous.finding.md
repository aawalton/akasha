# Claim

The Definition of `domains/roles/recorder.md` turns on a word naming two parties within 23 lines. It reads "what a principal's live agent leaves behind in a corpus." Read as the machinery takes `principal`, the live agent is the interviewer and the line is true. Read as every Responsibility below takes "your principal" — the interviewer that spawned this seat — the live agent becomes the recorder itself, and the line says the recorder is what the recorder leaves behind.

# Evidence

Raised by a review-instructions seat on `domains/roles/recorder.md`, which judged the second the reading a recorder actually arrives at, and could not land a repair: the Definition is reserved by Every Changed Line with no carve-out for a dispatched review.

Its evidence, which I did not re-run: it read `tools/lib/forward-turn.sh` whole and found it composes the recorder's body as "The principal said: ... The interviewer replied: ..." — written from the interviewer's frame, so there `principal` is the human. It also cites `dirty/docs/agent-roles.md:31` stating the role as "watch a principal's live session and turn it into committed material in a corpus", adding "it never speaks to Alan", which pairs the recorder with an archivist rather than an interviewer. It was explicit that `dirty/` binds nobody and so settles nothing — it raises which pairing the standing document is written for.
