# Claim

Ten of 124 findings in the store assert a universal negative over the instrument set — `nothing compares them`, `no instrument reports`, `no verb in the estate` — having opened one or two instruments. The same store enumerates documents, rows, sites and hooks routinely and well. No verb answers which instruments cover a given path, so that one population is the only one whose enumeration is a hand sweep every time.

# Evidence

Swept 2026-08-04 over all 124 findings then in `~/memory/findings/` (the count moved 122→125 mid-sweep under concurrent writes). Each of the ten was read whole.

The ten: `agent-harness/row-lands-against-domain-vision`, `agent-harness/duplicate-hook-scripts-unmeasured`, `agent-harness/persona-roster-has-two-stores`, `agent-harness/agents-tree-undrained`, `instructions-harness/hook-registration-unverified-both-sides`, `code-harness/deploy-cannot-reconcile-local-main`, `folder/folder-domain-coverage-unmeasured`, `code-repo/code-tree-work-unowned`, `principle/shape-rules-unstated`, `project/sibling-order-unexpressible`.

Eight of the ten sit in domains that own an instrument registry. Every one ran a real instrument and reported it accurately; none counted the set it then quantified over. `folder/folder-domain-coverage-unmeasured` is the sharpest: it DID run an exhaustive enumeration — the instructions tree's 14 checks — while its claim's subject is packages, which live in the code tree and its separate registry.

The same store does this well wherever the population is not instruments: `principle/rung-kind-misfiling-measured` parses every `**/*.md` (175 files) and states its exclusions; `agent-harness/shell-hook-hides-package-deps` reads all fourteen registered shell hooks; `code-harness/ratchets-report-fossils-as-advisory` sweeps 26 exemption structures, 8/15.

`~/instructions/tools/` holds 13 checks, 13 gates and 18 top-level verbs. Of the three whose docblocks could plausibly answer coverage, `unreached.ts` answers which quarantined surfaces nothing reaches, `owns.ts` who is answerable for a domain, `dag.ts` the domain graph's shape. None answers which instruments read a given path.

NOT MEASURED: the `ops` surface in `~/code` was not enumerated, so this does not claim the code tree holds no such verb. The split across the other 114 findings is a judgment applied consistently rather than a measurement; 10 of 124 is the figure read directly.
