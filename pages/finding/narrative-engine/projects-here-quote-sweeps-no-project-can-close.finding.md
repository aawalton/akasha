# Claim

Projects defined off this initiative are being given quoted intents that state a sweep rather than a state one project reaches, so a correct delivery arrives at verification unable to close what it quotes.

# Evidence

#19394 removed the Royal Road package cleanly and was verified pass, and neither line it quoted was any truer afterwards: "The code repo contains no unused code" and "Only code deployed off this workstation stands in the code repository". Both are met by whoever reports on them, for every project that quotes them, so no single removal closes either. The worker saw it and correctly declined to remove the quotes; the fault was upstream of him, in the defining.

The defining task already warns against this and names the shape — a line no instrument could settle goes back to the domain rather than being quoted. The warning did not catch it, because a sweep line reads as a perfectly good intent at the moment it is quoted: it is a state the domain should be in, and the project genuinely moves toward it.

Each remaining stage of `narrative-concepts-defined` closes one page type, while the intent it serves speaks of every kind of thing the narrative engine keeps. Quoting that line on each stage repeats this exactly, sixteen times.
