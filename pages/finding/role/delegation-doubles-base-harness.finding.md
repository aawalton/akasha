# Claim

The Delegation rung restates a claim the base harness already makes to this model. It was kept because the harness is a surface this repo does not control, but whether to lean on text Anthropic ships is a standing policy question rather than a reading-level one.

# Evidence

`domains/role.md` states: "**Wait for a delegate rather than running its work yourself.**"

Claude Code's own `Agent` tool description, shipped in the system prompt of every seat in this fleet, states: "Once you've delegated a search, don't also run it yourself — wait for the result." Verified firsthand by the archivist filing this, reading its own tool list rather than taking the report.

The reading kept the rung on two grounds: the harness text is a surface this repository neither controls nor can bind against, and the rung reaches non-search delegates and `ops agent` dispatches that the tool description does not.

What is open is general. `domains/agent-harness.md` says to keep an instruction only where Opus 5 would consistently make avoidable mistakes without it. Where the base harness already carries a claim, the answer turns on whether a surface outside this repository counts toward that test — which decides more rungs than this one.

The reading called this the closest Cut The Obvious call of the eleven rules on the surface.
