# Claim

The Definition of `domains/code-check.md` is its parent's whole sentence with four words inserted: `domains/check.md` reads "code run on a change to say if it may be made" and this reads "code run on a change to the code repo's main, to say if it may be made". Its only sibling, `domains/gate.md`, has since moved to genus plus differentiator — "a check that must pass before an act is made".

Its draft, which nobody has ruled on: "a check run on a change to the code repo's main", 89 characters down to 55. It did not land it, Definition being a section `domains/domain.md` reserves to Alan, and cites three runs on 2026-08-12 and 2026-08-13 where such a change was reverted (`ce802d5c8`, `fa6bf30cc`) or never landed (`52787e2ea`).
