# Claim

The Definition of `domains/code-check.md` binds its parent's claim a second time. It reads "code run on a change to the code repo's main, to say if it may be made", which is the whole Definition of the parent `domains/check.md` with a phrase inserted. Its only sibling, `domains/gate.md`, instead takes the declared term as its genus: "a check run on a file change". Against Single Authority the repair is "a check run on a change to the code repo's main" — 89 characters to 55.

# Evidence

Raised by a review-instructions seat on `domains/code-check.md` (report at ~/agents/claude-code-check-archivist-review-instructions/review-code-check.md). It justified the repair and did not land it, holding that Every Changed Line binds a Definition and nothing released it for this pass.

The reviewer reported the three Definition texts and the character counts. I did not re-read `domains/check.md` or `domains/gate.md` myself, and I did not verify the counts.
