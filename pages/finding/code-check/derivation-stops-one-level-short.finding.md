# Claim

Derivation stops one level short. A check derives its members from a source and hand-writes the set of sources; it derives what it judges and hand-writes where judgeable things arrive. The derived level is what a reader inspects and finds sound, so the hand-written level above it is where a new member lands unseen — and the population line stays true, because the bound counts what the walk found rather than what exists.

# Evidence

Five instances found in one day by seats verifying five unrelated children, each filed separately, none looking for this.

`check-eso-typings-fresh` derives its artifact list from the tree and identifies generators by a provenance line. A fifth generator omitting that line emits artifacts the population cannot see. Filed as `eso-generator-set-underived`.

`check-addon-sandbox-safety` takes member sets from a manifest and hand-writes the seven namespace NAMES, the manifest exporting no list of them. An eighth joins no arm, and the bundle count does not fall. Filed as `sandbox-namespaces-listed`.

A file class must be registered in seven places for dispatch to reach it. Four are compiler-forced; three are hand-written lists nothing derives from where a new class arrives. The guard over one of those three holds it against a SECOND hand-written list in the test file, so a class in neither passes green. Filed as `file-class-places-underived`.

Two addon gates derive their audit from the roster and no longer wake when the code that DERIVES the roster is edited. Filed as `roster-derivation-wakes-no-gate`.

No instrument settles whether a check wakes on the class it judges, because each check's judged class is prose. Filed as `judged-class-unknown-to-dispatch`.

WHY THE DERIVED LEVEL HIDES IT. A check that derives its members reads as sound, and is sound about the question it asks. Attention goes to the walk, the sophisticated part and the recently repaired one. The level above is a plain list that looks like configuration rather than a claim, and carries no bound of its own — nothing reports it is short, because short is indistinguishable from the tree holding no more.

NOT ESTABLISHED: how deep it goes. Every one of these was found by someone rebuilding one gate and looking at what fed it, which is not a search anybody runs. Whether the source-sets one level above these five are themselves derived, nobody has asked.
