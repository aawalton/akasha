# Claim

`review-tests` stage 2 has no line list and the task produces no report, so its reading has no bound. Both siblings carry one with a stated reason — `guided-close-read.md` gives it a whole stage, "a reading whose end he cannot see is one he leaves partway", and `review-instructions.md` says "Nothing reports a line you never listed". A seat judging nine assertions of forty hands back something no instrument can tell from a whole reading.

# Evidence

Raised by the review-instructions seat on `domains/tasks/code-quality/review-tests.md`, which would not write the bullet: doing so needs decisions it should not take — whether a code review owes a report at all, and where it would live.

I did not read the two sibling bullets for this, though I have read both documents earlier in this pass and both do carry a listing step with the reasons quoted.
