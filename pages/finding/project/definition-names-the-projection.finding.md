# Claim

`domains/project.md`'s Definition calls a project "a unit of work tracked as a row", while every carrier this domain records moving has moved row to document: `liveOn` retired, `project-seqs` retired, `depends-on` moved onto the document, status carried by the document with the row following, and `ops project create` stating the document rather than the row is the authority. Against File First on `domains/global.md`, the line names the projection rather than the source.

# Evidence

Observed by a dispatched `review-instructions` seat on 2026-08-11, which read the schema, ten project documents on disk, and `ops project create --help`, and cut the Intent entry that had already come true the same way.

Not measured: what concern should distinguish a project in the line's place. That is `define-definition`'s question rather than an instrument's, and the reader did not touch the line.
