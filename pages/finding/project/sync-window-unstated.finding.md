# Claim

Stage 5 of the singleton-deploy task omits the sync window that both `ops project check` and `ops project deploy` warn about.

# Evidence

Both verbs' `--help` name the window; the stage does not. The cost of the silence is a wasted stage-3 run rather than a wrong hand-back, which makes this the weakest of the six things the reviewing seat left standing and the reason it is recorded rather than repaired.
