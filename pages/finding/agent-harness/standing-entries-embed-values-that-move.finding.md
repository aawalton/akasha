# Claim

Emptying one rulings document a block at a time, every entry that had written a count into its prose was falsified by re-measurement within six weeks, and the only two entries that survived intact were the two ruling against writing counts. Nothing live states that rule, so the corpus keeps the failure and not the remedy.

# Evidence

Measured on 2026-08-07 while emptying `dirty/skills/visual-arts/rulings.md` and its sibling findings file, both written 2026-07-27 to 07-29.

Falsified by re-measurement. "0 of 273 `session-tracking` rows" — 445 rows today. "61 rows match the romance faucet's `Jen`" — 104. "78 match wealth's `project`" — 152. "29 `relationship-progress` rows spanning 2026-06-28 to 2026-07-27" — a closed window. "`skills/persona-craft/` mentions Zeli four times" — that directory is empty and returns 0. Each fell on one probe.

Survived. Two entries wrote no figure into their claim. One: "The zero is what carries this ruling; its denominator is not… quote the zero, and re-run the query rather than carrying a fraction." It names 273 and 302 as readings that moved while the zero held; 445 today, still 0. The other: "If an entry's meaning would change when its row's status changes, the entry is malformed. Membership in any set of rows is queried at read time and never written here; ordering may be written, because judgment has no field."

Nothing live carries either. `domains/memory.md`'s End State is the nearest and is scoped to an objective's description. `rg -uuu -in "queried at read time|copied here|row state" domains/` returns nothing.

Not measured: whether this holds across other quarantined sources. This is one document, read whole.
