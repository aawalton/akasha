# Claim

A definition stated in a delegate's brief, rather than quoted from the domain that settles it, reaches the code, the tests and the principal's own verification with nothing in that chain able to report that the domain says otherwise. Every artifact agrees, because every one of them descends from the brief.

A wrong implementation fails its tests. An invented definition passes everything.

# Evidence

On 2026-08-16 a brief for the seat sweep stated that an initiative is finished when its document quotes no unresolved intent. `domains/seat-assignment-initiative.md` states, in its Design section, that an initiative is done when its file is gone, and says nothing about an empty section.

The delegate built to the brief, wrote a test pinning it, and reported it green. It also caught and corrected two real faults in the same brief, so its judgment was working. The principal then verified independently, running the predicate against live initiatives and against a hand-made empty body, and confirmed both readings — the invented one among them — before reporting success.

The divergence surfaced only when a later request, to allow an empty section in every shape, made the two definitions collide: a freshly created stub would have read as finished and the seat holding it would have been released.

Not measured: whether other briefs written from this seat state definitions the domain does not, and how many. Only this one was checked, and only after the collision pointed at it. Nothing was measured about briefs written from other seats. No count was taken of how often a domain sentence exists for a definition a brief states.
