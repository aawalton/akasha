# Claim

A launch vocabulary of `spawned`, `opened` and `nested` stands in the code repository with no domain document declaring it, and 142 of 178 fleet modules name no capability at all.

# Evidence

Recorded from project #18836, which carried these two forward from an earlier removal and said plainly that neither was its to close and that nothing else carries them. The project has since been filed as findings and removed, so this is the only record.

The launch vocabulary — `spawned`, `opened`, `nested` — is used in code as though it were settled, and no domain document declares it. `Plain Or Declared` wants it either declared as a domain or renamed to a plain phrase, since nobody looks up a word they read as ordinary.

Separately, of 178 fleet modules, 142 name no capability. The row recorded that count as Alan's to rule on rather than a seat's, and it was never put to him.
