# Claim

The definition "everything an agent must read and obey" covers less than the `agent-harness` domain holds.

# Evidence

Raised by the review of `domains/agent-harness.md` on 2026-08-15. Supervisor, Instructions harness, Claude account, Interview session, Land and Memory are among the domains declaring `agent-harness` as a parent, and none of them is something an agent reads and obeys; the document's own Design and Intent lines are about database access, checks and which repository code stands in. The parent list was confirmed by grep on 2026-08-16. What the definition should say instead, and whether the domain's area is what should move rather than the line, was not judged.
