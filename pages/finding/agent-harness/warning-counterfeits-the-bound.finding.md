# Claim

Nothing binds the claim that a warning asking for a property counterfeits it. Measured over twelve sessions with ground truth known: adding a generic caution moved bound-SHAPED prose from 1/4 to 4/4 and left CORRECTNESS at 1/4, so afterwards a bounded claim and a bounded-sounding one read alike and the tell a reader would have used is gone. The corollary — an instruction telling an agent to state its bound IS a warning — reaches every task document in the estate.
