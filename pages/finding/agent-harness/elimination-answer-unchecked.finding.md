# Claim

An answer a seat reaches by eliminating the alternatives is never argued on its own
merits, so nothing in it invites a check. What such an answer actually asserts is a
claim about the OPTION SET — that the set was complete and that each rejection held —
and that claim is the one nobody tests, because the reasoning that produced it reads
as rigour rather than as a step. The option set is usually one query away from
whoever wrote it down.

# Evidence

Measured, in a lead's own ruling, and recorded there because it cost a wrong answer
to Alan: `dirty/skills/agent-harness/rulings/direction.md` under quarantine in the
instructions repo, in the passage this seat cut while emptying that source.

The persona axis was put to Alan as a question with three options — one narrow
surface under a hard predicate, forty copies, or delete the material. Two were
carried as refused, which left one, and `delete` was written up and reasoned forward
from. Alan then chose the forty copies for the first-person invariant, an option the
elimination had already discarded. The ruling names the mechanism itself: "an answer
reached by elimination never has to be argued for on its merits, so nothing in it
invites a check", and "the elimination that produced *delete* was the error, and it
is worth naming because it reads as rigor".

Nothing in the live corpus carries this. `rg -uuu -n -i "eliminat|option set|remaining
option|by exhaustion|only one left"` over `pages/domain/` exits 1 with no match, and the
same pattern over `~/memory/findings/` exits 1. The nearest live claim is Grounding on
`pages/domain/global.domain.md` — "Research done after the plan is formed reads identically and
confirms where it should have tested" — which is about the ORDER of research against
a plan, not about the option set a conclusion silently rests on.
