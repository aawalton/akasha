# Claim

The Rules on `domains/alan-email.md` read as a restatement of the code rules under `email/alan/rules/code/` — each names a class those already cover for particular senders — and nothing on the document distinguishes that reading from the true one, which is that `everything-else.md` applies them to a sender no code rule has claimed yet. Under the first reading Single Authority says cut them, and cutting them sends that mail to Alan.

# Evidence

Raised by the seat that read `domains/alan-email.md` on 2026-08-13 under `review-instructions`, and relayed here rather than re-derived: I did not open the five rules, `everything-else.md`, or the code rules they overlap.

That seat reports settling the true reading only after reading the thirty-seven-rule order at `email/alan/rules.md` and the eleven code rules involved, which is more than a reader of this document alone would have in hand. It states plainly that the next reviewer will meet the same fork.

Nothing here measures how a reviewer without that context has ruled before, or whether any of the five has ever been cut and restored.
