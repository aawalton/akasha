# Claim

Measured Figure stands in `domains/memory.md`'s Principles and has a rule's shape: it specifies the act, leaves only whether it was done, and applies to one case — the same shape as Staleness, filed a section below it as a rule.

# Evidence

Measured 2026-08-11, on a `review-instructions` reading of `domains/memory.md` dispatched from `review-documents`. The reading raised it and declined to land it; the documents were re-read here rather than taken from it.

`domains/memory.md`, Principles, Measured Figure: "Never count, list or measure what stands today, in an objective." Its `# Rules` section holds Staleness ("Never report what a memory document records about the world as stale, initiative or theme excepted") and End State.

`domains/rule.md`: "a standing instruction that specifies the act, leaving only whether it was done." `domains/principle.md`: "a truth packed tight so it can be applied to many different cases." The act names one case — an objective — and leaves only whether a figure was written.

`tools/document/schemas/principle-or-rule.ts` puts it beyond an instrument: "What separates the kinds is the section each stands in and what a reader owes it, neither of which is a bound." The two kinds share one shape and one set of caps, so nothing mechanical can tell a misfiled unit from a correctly filed one.

Measured Figure is the only member of that Principles section, so moving it empties the section and the heading goes with it. The reading's recommendation was to move it and drop the section; it left it standing because the change rests on judgment and lands in a domain's Principles and Rules.

Not measured: whether other domains carry a similarly misfiled unit, or what a reader has done differently for having met this one as a principle.
