# Claim

`domains/domain.md`'s Every Changed Line binds each line an agent would change in a domain's Definition, Design, Intent, Principles or Rules to Alan, stating no exception. `domains/role-responsibilities.md` carries the parallel rule and states a carve-out that domain.md does not: a cut a dispatched review lands is not a changed line. On domain.md's wording alone, a dispatched reading of a domain document can land nothing.

# Evidence

Read by a dispatched `review-instructions` seat on `domains/agent-harness.md`, 2026-08-11. That seat assumed the carve-out held here too and confined itself to cuts; it cut nothing, so nothing in that run turned on the assumption.

Not measured: whether any third document restates either rule, and which of the two wordings is the intended one.
