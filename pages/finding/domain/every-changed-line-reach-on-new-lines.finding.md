# Claim

**Every Changed Line** on `page-types/domain.md` binds each line you would CHANGE, and a task writing a domain that did not exist before writes lines that are not changed ones. `domains/tasks/ops/review-command.md` stage 3.1 re-enumerates the same five sections to bind the writing case, which reads as a restatement Single Authority would cut — and cutting it would unbind the case the bullet exists for, if new lines fall outside the rule.
