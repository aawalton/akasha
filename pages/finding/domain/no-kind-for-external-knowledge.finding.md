# Claim

The estate has no document kind for durable knowledge about an external system it depends on. Such a fact states no act, so it is neither principle nor rule; it defines no term of ours; a Design entry takes a decision of ours, which a third party's behaviour is not; and a finding is filed before anyone has judged what it means, which is the wrong shelf for something settled. Two surfaced in one night: one sits in quarantine because its seat could not place it, the other was cut.

# Evidence

Measured 2026-08-08, first-hand, from two independent seats' work during the `dirty/` sweep.

The first stands at `dirty/maybe-keep/code/packages-agents-oauth-docs-account-selection.md`: Anthropic's usage `limits[]` carries independent per-scope buckets, so a scoped or session 429 does not raise the weekly-all reading, and a mid-window 429 beside a 0% seven-day figure is upstream truth rather than a parse artifact. It then wrote, in the keep itself: "I have deliberately NOT filed it as a finding either... Filing it there would be choosing it a home, which buries the thing worth recording: the estate has no kind for knowledge about an external system it depends on."

The second was cut tonight and survives only in git: model verbosity bias is per-invocation, so decomposing dialogue across separate seats imposes a floor no prompt tuning reaches. Its seat swept five roots, found it carried nowhere, cut it because the mistake it prevents needs an architecture nobody has built, and named it the one cut in its run it would want a second opinion on.

Neither seat was answering this question. Each met the gap doing something else and recorded it rather than forcing a placement.

What the estate holds: `domains/domain.md` gives a domain a Definition, Design, Intent, Principles, Rules and Tasks; `domains/finding.md` defines a finding as "a single observation about a domain, filed before anyone has judged what it means"; a list holds an enumeration. A fact about how a third party behaves fits none. And these differ from a stale code description in the way that matters: nothing in either repository can be read to recover them, because the system they describe is not ours.
