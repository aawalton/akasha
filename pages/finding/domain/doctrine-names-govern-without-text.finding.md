# Claim

Working code justifies its own shape by doctrine names the estate never wrote down. Four names carry 335 citing files under `packages/`, none stated in any live document and none refused by any mechanism. Individual findings stand against several names; nothing carries the class. This is a governance gap rather than a documentation one: a citation is what a reader obeys, so the estate is governed by titles whose text does not exist — and one name is glossed three different ways by its own citers.

# Evidence

Measured 2026-08-08, first-hand: `git ls-files 'packages/**'` in `~/code` for citations, `rg -uuu -i` over `domains/`, `tools/`, `notices/` and `settings/` for statements. These are floors: my first pass matched one spelling of three.

Citing files, then live statements:

- Reliability — 205, 0
- Rule of Three — 60, 0
- Consume-on-Demand — 59, 0
- Omit Needless Ink — 11, 0

Two more were measured by seats: the prohibition on relaunching a failed agent, twelve citers, and "the C+D contract", six. The second is the sharpest evidence that a name without a text drifts — three of its six citations gloss it three ways: "effort over outcome", "meter the activity not the content", "scales decoupled".

`code-repo/doctrine-names-cited-without-paths.md` states why no instrument reaches any: a name carries no path, so a dangling-citation check has nothing to resolve.

What makes this one claim rather than six is that a single decision answers all of them, and answering it six times will not produce one answer. Every name sits in the same position, and each is currently being met by a different agent emptying a different quarantined source.

MEMBERSHIP TURNS ON TWO TESTS — invoked by LIVE code, and refused by no mechanism — and each has been failed once. Five names were in this list and fail the second: `Boundary Parsing` (294), `Long-Running Worker Shape` (97), `Functional Type` (32), `Pages Access Boundary` and `Unix Philosophy` are stated in no live document and each REFUSED by a wired check — `boundary-parse`, `check-worker-shape`, `check-functional-type`, `no-raw-pages-sql`. `grep -rhoE 'Authoritative principle: …' packages/` enumerates twelve such names in one pass; I filed without it, having measured only half the test. `Package Boundary Criteria` was offered as a fifth member and fails the FIRST: 34 files name it, every one under `instructions/dirty/`, none in `~/code` or `domains/` — its only callers are the quarantined sources being emptied. Unstated is not the defect. Unstated, unrefused and invoked by working code is.
