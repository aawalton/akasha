# Claim

The Design line "A live path nothing guards is a gap, not permission" on `domains/agent-governance.md` spells `guards` where every other layer of the same machinery spells `governs`: the slug `agent-governance`, the gate `read-what-governs`, the verb `ops instructions governs`, the function `governorsOf`, and `agent-governance.ts`'s own "nothing governs this path". It is the sole live site of `guards` in that sense.

# Evidence

Raised by the dispatched reviewer of `domains/agent-governance.md` on 2026-08-07 and relayed here unjudged, against Ubiquitous Naming on `domains/global.md`. It reported the claim beneath the line as sound — `standingOn` returns a pass for an ungoverned path, and this line is what stops a reader taking that pass as a licence — so what it proposed was the one word.

The five sites are the reviewer's; I confirmed only that `guards` appears in this Design line. I did not run a corpus-wide count of `guards` against `governs`, so "sole live site" rests on the reviewer's search.

`live-path-unattested.md` in this domain records a different defect in the same sentence — whether `live` may qualify a path. Neither subsumes the other, and a repair to one leaves the other standing.
