# Claim

The Definition of `domains/agent-governance.md` — "which documents must be read before an agent acts on a path or in a seat" — has two readings and only one is true. Reading a path is ungoverned; what is judged is a change to one. The seat half is exact, `hold-seat` sitting over every tool call, so the ambiguity is in the path half alone.

# Evidence

Raised by the dispatched reviewer of `domains/agent-governance.md` on 2026-08-07 and relayed here unjudged. It reported a replacement ready to apply — "which documents must be read before an agent changes a path or acts in a seat" — left standing because Every Changed Line on `domains/domain.md` reserves a Definition for Alan.

Its grounds, none of which I re-ran: `tools/read.ts` levies no gate; every `ops instructions read` in its review passed without a governance check; `read-what-governs` is entered in `GATES`, which the write verbs run; the code-repo hook matches `Write|Edit` only.

Not measured: whether any reader has taken the false branch. `seat-half-unstated.md` in this domain records that the Design states the path half and leaves the seat half nearly unstated; that is a separate claim about the Design and neither subsumes the other.
