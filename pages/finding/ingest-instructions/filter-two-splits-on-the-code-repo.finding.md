# Claim

The second filter counts a mechanism that refuses the act and counts nothing in the code repository, and almost every refusing mechanism in the estate is in the code repository. The two clauses point opposite ways on the same artifact. A reading that reconciles them exists and the text does not state it, so each seat derives it alone: two reached opposite readings tonight and one changed its mind between its two sources, mid-run.

# Evidence

Measured 2026-08-07, first-hand, during the `dirty/` sweep.

The task's stage 2 states it as: "counting a live document, and a mechanism that refuses the act, and nothing in the code repository. Refusing is stronger than stating, so a gate that turns the act away retires the prose describing it. Code over there carries nothing".

Where the refusing mechanisms are: `~/instructions` holds 12 files under `tools/gates/` and 19 under `tools/checks/`. `~/code` holds 736 under `packages/infra/checks/src/`. So the great majority of what can refuse an act sits in the repository the same sentence says carries nothing.

Seats have cut real blocks on those code-repo checks. Three cited to me tonight: `liveness-routing.ts`, quoted as refusing that "a new bypass cannot be WRITTEN through any catalogued evidence route"; `check-messages-write-chokepoint.ts`, refusing a second write point; and `check-no-hardcoded-message-source`.

A coherent reading exists. The clause's own warrant is reachability — "a claim held only there is one no reader of this tree can reach" — and a refusal reaches you whether or not you go looking, where passive prose does not. Under that reading a code-repo gate counts and a code-repo docblock does not, which is the same line "refusing is stronger than stating" draws.

That reading is derived rather than written, and the derivation is not free. One seat reported leaning on code docblocks as second-filter evidence through its first source and separating gate from docblock only from its second source on, marking which basis each verdict rested on. Another recorded getting it right first time and said so explicitly, which is what a seat does about a thing it had to work out.

No verdict is known to have turned on it — the seat that changed its reading reported every affected section failing the third filter independently. The exposure is that a wrong resolution cuts on a carrier nothing can reach, and a cut needs no positive evidence to look sound.
