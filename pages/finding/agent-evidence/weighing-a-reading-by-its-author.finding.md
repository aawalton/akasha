# Claim

An agent discounts a reading because it produced it, and trusts one for the same reason. These are one error: authorship substituting for measurement. Only the trusting direction is guarded, because it reads as carelessness. The discounting direction wears the costume of good practice, so nothing catches it, and what it throws away is a reading that was taken — while what survives is whatever a second party happened to say.

# Evidence

Both directions on 2026-08-26, in one agent, hours apart.

Trusting: a batch removing 143 export-forwarding lines reported 143 files cleared, and the report was taken for the outcome. It was accurate about what the batch did and silent on what that did. 55 files stood at zero bytes and 656 named imports resolved to nothing. Earlier the same night, a driver script wrote `DID` per file without reading the exit code of the `ops write` it had just made, and went on recording success after `ops` itself had stopped working; the log was discarded and the tree measured instead.

Discounting: the same agent reached a claim about its own instruments — that a check tends to answer whichever adjacent question was quick to write — and declined to file it, on the ground that it had generated the claim from its own failures and was the least reliable witness available. The claim was supported by five instances across two agents and unrelated code. A peer filed it as `finding/agent-harness/the-cheap-question-is-the-adjacent-one`, whereupon the agent agreed with it. Nothing between the two positions was measured; only the author changed.

Not measured: whether the discounting direction is common, or whether this is one instance. It was visible here only because a second party was in the room to file what was withheld, and an agent working alone would produce no trace of a reading it declined to record.
