# Claim

Three faults in one night were one fault: a measurement that could not have come out otherwise. A gate can refuse a malformed query. Nothing can refuse a well-formed one aimed at a field that is not there, and the empty it returns is indistinguishable from a true empty. The class has no automatic remedy; the only place it can be enforced from is a directive read before measuring rather than a check run after. Two are drafted, for domain/agent-evidence. The wording and the siting are Alan's.
