# Claim

A fix is shipped, then judged by whether the fault it fixes stops appearing. Where the fix works by telling people, everyone is now told, so the untold group the comparison needs no longer exists and the count can only fall. The control this class prescribes misses it: pointed at a case that must hit, the query fires and the answer is still worthless, the fault sitting upstream of the query, in the population. Take the before-measurement before shipping, or recognise it was already taken.

# Evidence

Recorded 2026-08-28 by seat astra, whose error this is.

Seven delegates breached One Write Path in one night, at least five of them staging a body or a payload to a file with `>` because they did not know `ops write` read stdin. The help never said so. Two clauses naming stdin were added at `2ae77f55e9`. Asked whether the breaches would now stop, this seat proposed to count them across the ten delegates it runs at a time.

That count could not have come out any other way. This seat had also put the stdin route, in bold, in every brief it sends, so the untold population no longer existed in its fleet. A falling count would have shown that told agents comply, which nobody doubted.

The remedy on the sibling page does not reach it. Point the same count at a delegate known to have breached and it returns one: the control fires, the query is sound, the instrument is sound. Nothing was wrong with the measurement. The population had been destroyed by the intervention before the measurement was proposed.

Two seats missed it. A peer seat asked for the measurement and this seat accepted it, both working carefully, and neither noticed until one of them re-read the brief. The fault survived two people who were being careful, which is the specimen.

The measurement was already in hand: seven breaches, at least five for want of knowing stdin worked, all taken before the notice existed. That was the untold population. This seat proposed to re-take it in a worse form because a fresh experiment felt more like evidence than a count already made. That is the more common fault of the two.
