# Claim

Where a failure's signature is that the failing party stops producing, an instrument reading that party's own output can only report once something else has revived it. A stalled seat's transcript is written by the seat whose failure is that it writes nothing. Site the observer on code still running while the failure happens: ask who writes the evidence, and whether they are alive at the moment. Nothing under the domain pages binds where an observer sits.
