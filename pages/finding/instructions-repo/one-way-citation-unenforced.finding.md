# Claim

Nothing enforces One-Way Citation: three entries on `domains/lists/unresolved-checks.md` named a live memory document from the instructions repo and passed all twelve gates on every write, and no check or gate in the repo reads for the breach.

# Evidence

Measured 2026-08-11, on a `review-instructions` reading of `domains/lists/unresolved-checks.md` dispatched from `review-documents`. That reading found and repaired the three entries, so the instances are gone; what stands is that nothing catches the next one.

`domains/folders/instructions-repo.md`, One-Way Citation: "Never name a particular memory document from the instructions repo. Citation runs one way, which is what lets the two repos be gated, moved and deleted from separately. A glob or a template names a shape and survives; a named document rots where nothing looks."

The three entries each named `athena/harness-in-instructions`, a live document in the memory repository. The reading reports twelve gates passing on each of those writes, and repaired them to `held:` plus the reason, which routes the work by shape and names no document over the wall.

`tools/gates/` holds twelve files: `document-conforms`, `domain-slug-stem`, `domain-slug-unique`, `hold-seat`, `hook-liveness`, `links-resolve`, `read-before-write`, `read-the-schema`, `read-what-governs`, `repo-agrees`, `token-ceiling`, `typecheck`. `tools/checks/` holds twenty-three, none of them about citation direction. `links-resolve` reads markdown links and would not see a bare path in prose in any case.

Not measured: how many other instructions documents name a memory document today, whether the rule is mechanically checkable at all given that a memory path and an ordinary phrase can look alike, or what the three entries cost before they were found.
