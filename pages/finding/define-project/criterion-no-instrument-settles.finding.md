# Claim

A criterion can be written that no instrument in the system could ever settle, and nothing at definition time catches it. It reads as ambitious rather than as impossible, the work built against it is the right work, and the defect surfaces only at verification — where the verifier can neither tick the box honestly nor fail a delivery that did what it was asked.

# Evidence

Two instances in one tree, both found by verifying seats and handed back as definition failures.

#18349 asked that "every registered check is dispatched by the change class it judges". Settling it needs each check's judged class machine-known, and the estate does not hold that: it is stated in hand-written prose per check, a static scan under-reports it, gating every tracked file that projects to a node type is unlandable at 722 violations of 16,933 members, and exempting the rest by hand is the list `Derived Reach` forbids.

#18413 asked that "every surface the store rejects on is scanned". That asks what Apple's validator reads. The verifying seat established only the description is tied to observed behaviour; the rest is inference. It left the box unticked rather than report success on what it could not verify, which leaves a closing project carrying what reads as a shortfall.

WHAT SEPARATES THIS FROM A GAP-WRITTEN CRITERION, the failure it will be confused with. A gap-written criterion is true when written and misleading once ticked, because its description asserts the defect as the reason it was met; the repair is a rewording and the box is still ticked. An unsettleable one can never be ticked honestly, whatever anyone builds. Telling them apart means asking what instrument would settle it and what that instrument would have to know — a question nobody asks at definition, because the criterion reads as the point rather than as a claim about measurability.

THE TELL THEY SHARE: both range over EVERY member of a population whose relevant property is not machine-known. "Every registered check" over a judged class held in prose; "every surface" over a validator nobody here controls. The universal quantifier is what makes it sound like the objective, and the unknown property is what makes it unsettleable.

NOT ESTABLISHED: how often this happens elsewhere. Both come from one initiative, verified by seats briefed to escalate wording, so somebody was already looking.
