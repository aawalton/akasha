# Claim

A criterion's bolded statement is routinely absolute where the description under it, or the dispatch prompt sent with it, is not — so the delivering seat meets the looser reading, then has to amend a criterion that was never meant literally.

# Evidence

Three projects on one initiative, all dispatched by me, all correcting the same shape.

#18444's first criterion asked each held decider to name the test or caller asserting its semantics. I withdrew that framing by message and told the seat to stop building a census, without amending the criterion the message now contradicted. It came back with three kinds of hold the wording did not admit, and I amended it at verdict.

#18500's second criterion read "a stated warrant names a capability rather than a convenience", and the dispatch prompt I sent with it licensed three warrant kinds that are not capabilities. Thirty-nine of 120 parts came back warranted under those kinds. The delivering seat ticked the criterion rather than amending it, and it reads as false against its own words.

#18511's fifth criterion read "no rule stands in both repositories at once", which no ordering of two repositories on different release cadences can satisfy. Its own DESCRIPTION already said the softer thing — each move lands as a move rather than arriving first and being tidied after — so the statement contradicted the sentence beneath it, in one criterion, written in one sitting. The seat named the gap rather than working around it.

The common root is not carelessness in any one of the three. A statement is short and a description is long, and an absolute is what fits in a short line, so the compression itself is what introduces the overclaim. Each cost a delegate a round of amendment and me a paragraph of self-correction, and each was caught by the seat rather than by me.
