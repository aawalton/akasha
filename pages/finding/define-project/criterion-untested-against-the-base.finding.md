# Claim

Nothing binds the pre-dispatch test for a criterion already true before the work starts: run it against the untouched base, and a pass there proves it is not a criterion. `domains/tasks/lead/define-project.md` reaches a criterion no instrument settles and one naming a method, and neither is this. The three deploy-track build tasks carry the diagnostic — "a verification that cannot fail proves nothing" — on the seat running the verification, never on the lead writing the criterion.

# Evidence

A companion to the standing `define-project/criterion-truth-fixed-before-verification.md`, filed the same day by a sibling seat from `rulings/rows.md`. That one carries the class observation and is not re-filed here. This carries what it lacks: the pre-dispatch test, and the two neighbouring classes.

Found emptying `dirty/skills/agent-harness/rulings/instruments.md`, whose ruling of 2026-07-28 records Rule of Three met at five instances across two trees. The judgment is kept verbatim under `dirty/maybe-keep/`; filed here because that copy is queued for its own sweep.

The class: a criterion whose pass condition is already true before the work starts. Not a wrong instrument and not a wrong population — a criterion that describes the present and reads as a result. A worker satisfies it honestly, observes a true pass side and a true fail side, and every word reported is correct, which is why the ruling calls it the one that cannot be caught at hand-back: the evidence is genuine. The executable form is to run the criterion against the untouched base; a pass there means it is not a criterion.

The two neighbours, each prescribing a different remedy, which is why the ruling refuses to merge them. An ALARM whose off-state is unreachable lies: it fires always, and nothing printed beside it repairs that. An EXEMPTION whose on-state is unoccupied is inert, misleading only if its emptiness goes unreported. This third is neither: a criterion that will be marked met, by honest people, having caused nothing to happen.

I verified the live carriers rather than taking the sibling finding's word. `rg -n "cannot fail proves nothing|what a failure would look like"` over `domains/` returns exactly three lines: `build-child-deploy.md:33`, `build-singleton-deploy.md:35`, `build-parent-deploy.md:39`.
