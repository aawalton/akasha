# Claim

A retired-term sweep measures itself over identifiers and prose and goes blind on help text — the surface a reader actually meets. Across #17960 the most-missed sites were `--flex` help and `ops seat start` flag help, each found only after the sweep had reported the term gone.

# Evidence

WHO REPORTED IT. #17960's manager, at hand-back, naming it the pattern that outlives its own tree: of every miss across the project, the most-missed surface was help text rather than comments. It reached that after six landing attempts in the same files, so the sweep had been re-derived several times and still left those sites.

WHY A SWEEP CANNOT SEE THEM. A verb's help is assembled from flag descriptions and long strings spread across its registration, and it is read by running the verb rather than by opening a file. A search over identifiers passes straight through it, because nothing in it is an identifier; a search over prose finds it only where the searcher already thought to include the sources of generated text. So the surface with the most readers is the one a coverage count never enumerates.

WHAT IT COST HERE, TWICE OVER. #18034's `--flex` help asserted a rule the code did not hold — that only a spawned seat carries a flex — while the predicate refused something narrower. The help was not merely stale; it was the place the false claim lived, and the lead's verification found it by reading the text beside the code rather than by any sweep. Separately, `ops seat whoami --help` still reads `parentAgentId` in mode's vocabulary for a launch question, a year of vocabulary work having passed over the verb a seat runs to learn what it is.

WHAT A SWEEP WOULD HAVE TO DO. Run each verb it touches and read what it prints, then compare that against the tree it just swept. Nothing does this today, and the instrument would be cheap: the fleet's verbs all answer `--help` and their output is text.

THE CORROBORATION FROM OUTSIDE. During #17960 the seat on #18034 wrote fresh prose in the retired vocabulary while doing careful, unrelated work, and said plainly that the word read as ordinary to it. A reader cannot flag a term they have no way to know is retired, which is exactly why the surfaces they read are the ones a sweep must cover.
