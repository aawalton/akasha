# Claim

Most retired-domain entries record a replacement that never happened. The word is still live in the very sense the entry declares retired, so the registry reports work as finished that was never started — and a seat holding such an entry substitutes into live prose, which is how a claim in `review-check.md` came to be inverted and two domain documents came to say "session" where they meant a run of a task.

# Evidence

Twenty-seven entries stand. Sense inventories over the live corpus, `dirty/` excluded, sort them by one question: is the word still used in the sense the entry names?

REPLACEMENT DONE — the entry is a true record and the guard it was written to be. `perimeter`, `substrate` and `researcher` have zero live uses of any sense. `pin` has one residue, at `tools/lib/read-log.ts:111`. `slice`, `crossing`, `turns-on`, `identity` and `surface` have zero live uses of the senses their entries name, though four of them reach a plain sense that is still live and so owe the scope clause `retired-domain.md` now requires.

REPLACEMENT NOT DONE — the word stands in the sense the entry retired. `door` in 337 places, including four agent system prompts that tell a reader to "read a file through the door" with nothing declaring what a door is. `axis` in `export type Axis`, `export const AXES`, `SEAT_AXES=(persona domain role task)`, a help string, a check message, and a drift check written to guard that pair. `verb` in four doors' `--help`, a gate's on-disk JSON field, and a registry file format a code-repo check reads. `quarantined` in 89 places including an exported constant and two gate skip strings. `cut` in twenty instruction lines and two schema field descriptions. `red` in six build-task documents. `wake` in all six build tasks and in `loop.md`. Also `walk`, `levies`, `residue`, `falsified`, `referrer`, `mints`, `hold`, `pass`, `sweep`.

`cut` is the sharpest. Plain English does not merely fail to carry it — it inverts it. "The project was cut" means cancelled; the corpus means chartered. `define-project.md:22` writes "why the project was cut", and an obedient reader takes the opposite of the truth. It cannot simply be swept: `Cut The Obvious` is a principle heading on `agent-harness.md` with four anchor links pointing at it.
