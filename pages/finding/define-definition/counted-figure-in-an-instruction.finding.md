# Claim

`domains/tasks/definer/define-definition.md:38` counts another document's contents — "its Design is six sentences in four paragraphs", of `domains/domain-definition.md` — so the line goes false the next time that document is edited and nothing reports it. `domains/memory.md` **Measured Figure** forbids exactly this in an objective; no instruction in the instructions corpus forbids it here.

# Evidence

Filed by the seat dispatching the 2026-08-14 `review-instructions` reading of `domains/tasks/definer/define-definition.md`, from that reading's hand-back. That reading judged the count true today and left it, saying a later reading catches it.

I read `domains/memory.md` myself: **Measured Figure** reads "Never count, list or measure what stands today, in an objective", and its warrant is that nobody re-reads a figure to check it still holds, so a wrong one is trusted exactly where it misleads. Its scope is an objective, which is a memory document, so it does not reach an instruction.

Not measured: I did not open line 38 or count the Design section of `domains/domain-definition.md`, so whether the figure is right today is that reading's. Nothing here searches the instructions corpus for other counts of this kind, and nothing here says whether the principle should be widened or the line simply rewritten.
