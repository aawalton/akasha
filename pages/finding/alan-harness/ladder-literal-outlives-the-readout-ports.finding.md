# Claim

The green-day-units ladder has one consumer no readout project retires: a faucet folding the same rows to a different reading, which needs the literal standing.

# Evidence

Reported independently by the seats on #18908 and #18909 on 2026-08-12, from opposite sides of the same seam.

`GREEN_DAY_UNITS_LADDER` stood in `daily-stoplights.ts`; re-measured 2026-08-27 it is declared at `readouts/ring/ladder/ladder.ts:3` and imported at `readouts/daily-stoplights.ts:6`, which uses it in `aggregateValueUnits` at lines 41-47. #18908 ports the value and inbox readouts to SQL and would delete it; #18909 closes `upkeep-stoplights.ts` and `persona-stoplights.ts` behind it — both now stand at `readouts/upkeep-stoplights.ts` and `readouts/persona-stoplights.ts`, and neither names the ladder. Those account for every readout consumer.

`readouts/stoplight-mean-points.ts` is the one left, and it still stands: it imports the ladder at line 2 and `aggregateValueUnits` at line 4, and reaches both at lines 131 and 134-150. It is the `stoplights` faucet, and it folds the same relationship-progress rows to a DIFFERENT reading: the six value circles with one persona held out, settled to a fixpoint. No function answering a readout answers that, so it needs `aggregateValueUnits` and the ladder to keep standing. `faucet-document-check.ts` read the ladder too; that file is gone as of 2026-08-27.

So #18792's first criterion — that searching for one of these values finds the reader rather than a literal — cannot fully pass on the readout projects alone. One literal survives them all, with a live consumer that is not a readout.

Neither seat absorbed it and neither was asked to. Widening either project to cover a faucet fixpoint would have been stretching a readout port around something that is not a readout.

What would settle what this means: whether the faucet's fold should read the same projection the readouts now read, or whether a second reading over the same rows is a thing the system means to have. That is a question about the faucet rather than about the ladder.
