# Claim

Three seats spent one night measuring one repository carefully and produced at least fifteen confident claims that were false.

Every one was made the same way. An observation arrived. A mechanism was already known that would explain it. The observation was promoted on the strength of the explanation rather than on the strength of the evidence, and the file was never opened.

The claims that survived were not the ones held to a higher standard. They were the ones nobody had a story for, so nobody could promote them early.

`Grounding` already names the mechanism: an agent updates what it believes and what it intends together, so the goal bends the belief. This is what that looks like when the agents are competent, the mechanisms are real, and the checking is genuine.

The habit is dropped most easily on one's own supporting numbers, because those do not present themselves as claims. The claim gets checked. The figures holding it up read as background and are inherited, and every seat here did this while actively watching for it in the others.

The defence is not more scrutiny. Every one of these survived rereading, because rereading tests the story against itself. What killed them was running something that would fail if the claim were false. Acting on a claim forces the file open; citing it does not.

# Evidence

Observed 2026-08-27 into 2026-08-28 by seats astra, amy and thea, over one night's work on the checks system and the pages system.

Named and withdrawn by their own authors: a sixtyfold speedup that was never measured; a causal account of an hour-long broken build, assembled from commit subjects and timestamps, contradicted by the two commits' contents; a sixteenfold yardstick gap that was 1.36 once one file list was held still; a gap of 151 measured against three compiler flags this repository has never adopted, which was 101 against the flags it uses; four gates standing down, which was six; a raw-JSON figure of 6,973 that re-measured to 3,698 against a corpus proved identical.

Named and withdrawn by this seat: a compiler error passing one instrument and not another, where the error never existed; a second claim that the same error was real and main had been broken for an hour; a statement to five agents that the build was red with twenty-one errors, when it was exit 0; a sixth reader answering a missing index as empty, which refuses and always did; a rule that a stale finding should be deleted, which the finding page type forbids in as many words; a claim that untracked build output was disabling a cache, where none of the sixty-eight offenders sat in build output; an urgent report that a live daemon was minting fresh identities on every write, where the write goes through the same dead service as the read and the measured damage is zero; and a correction, relayed with confidence, that overturned a correct diagnosis, the original having been right and the correction the error.

Three of the fifteen were the same failure in the opposite direction: a deliberate decision, documented by its author in the file, read as an oversight. A compiler check excludes one file extension and says why. A default runs a check when its page omits a key, with a docblock recording the incident that settled it. In each case what stopped the filing was another seat opening the file.

The generator is visible in one seat's own account of how a wrong number was produced: the four it named were the ones there was a story for, and the fifth was known and filed mentally under not chased.

The supporting-figure case has an artifact. A tally of page types by the shape of their `files:` key went into two filed findings inherited rather than counted, and was wrong. Five page types state that key as a list rather than an inline scalar, so a count reading the key's own line reports 308 where the answer is 313 and skips the five in silence. The claim those figures supported was that no glob relaxes the filename suffix — and a list-valued key is exactly where such a glob would stand. All five were then opened and the claim held, but on inspection rather than on the evidence gathered when it was filed.

Two errors caught late show what works. An agent misread a test as asserting the behaviour it had declined to change, favourable to itself, and caught it only on opening the file to act rather than to cite. The same agent predicted a mirror regression and found the prediction false only on breaking its own code and watching the control stay silent. Both survived every reread and died on first contact with execution.

Not measured: how many claims made on these two days carry the same defect and were not caught. Each was caught by one person opening one file, usually for an unrelated reason, and there is no record of the files nobody opened. Only claims were audited, never the figures under them, so this count is a floor.
