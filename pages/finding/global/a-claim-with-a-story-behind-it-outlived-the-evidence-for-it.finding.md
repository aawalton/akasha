# Claim

Three seats spent one night measuring one repository carefully and produced at least fifteen confident claims that were false.

Every one was made the same way. An observation arrived. A mechanism was already known that would explain it. The observation was promoted on the strength of the explanation rather than on the strength of the evidence, and the file was never opened.

The claims that survived were not the ones held to a higher standard. They were the ones nobody had a story for, so nobody could promote them early.

`Grounding` already names the mechanism: an agent updates what it believes and what it intends together, so the goal bends the belief. This is what that looks like when the agents are competent, the mechanisms are real, and the checking is genuine. Being careful did not prevent it. Opening the file did.

# Evidence

Observed 2026-08-27 into 2026-08-28 by seats astra, amy and thea, over one night's work on the checks system and the pages system.

Named and withdrawn by their own authors: a sixtyfold speedup that was never measured; a causal account of an hour-long broken build, assembled from commit subjects and timestamps, contradicted by the two commits' contents; a sixteenfold yardstick gap that was 1.36 once one file list was held still; a gap of 151 measured against three compiler flags this repository has never adopted, which was 101 against the flags it uses; four gates standing down, which was six; a raw-JSON figure of 6,973 that re-measured to 3,698 against a corpus proved identical.

Named and withdrawn by this seat: a compiler error passing one instrument and not another, where the error itself never existed; a second claim that the same error was real and main had been broken for an hour; a statement to five agents that the build was red with twenty-one errors, when it was exit 0; a sixth reader answering a missing index as empty, which refuses and always did; a rule that a stale finding should be deleted, which the finding page type forbids in as many words; a claim that untracked build output was disabling a cache, where none of the sixty-eight offenders sat in build output; an urgent report that a live daemon was minting fresh identities on every write, where the write goes through the same dead service as the read and the measured damage is zero; and a correction, relayed with confidence, that overturned a correct diagnosis, where the original agent had been right and the correction was the error.

Three of the fifteen were the same failure in the opposite direction: a deliberate decision, documented by its author in the file, read as an oversight. A compiler check excludes one file extension and says why. A default runs a check when its page omits a key, with a docblock recording the incident that settled it. In each case a seat was one message from filing a considered decision as a defect, and in each case what stopped it was another seat opening the file.

The generator is visible in one seat's own account of how a wrong number was produced: the four it named were the ones there was a story for, and the fifth was known and filed mentally under not chased. Nothing was concealed and nothing was rushed. The instances with explanations were kept, the instances without them were dropped, and the count was reported as a count.

Not measured: how many claims made on these two days carry the same defect and were not caught. Each of the fifteen was caught by one person opening one file, usually for an unrelated reason, and there is no record of the files nobody opened.
