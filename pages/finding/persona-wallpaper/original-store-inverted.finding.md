# Claim

`persona-wallpaper` states an intent that inverts its own Design line, and nothing is aimed at closing the gap.

Design says the local tree holds the original and the object store is where it is published. Intent says the object store holds the original and the local tree is a cache. That is a gap rather than a contradiction, but no work names it: the initiative under this page type quoted only the other intent line, and has since been deleted.

# Evidence

Read 2026-08-22.

`pages/page-type/persona-wallpaper.md` Design: "The local tree holds the original and the object store is where it is published." Intent, immediately below: "The object store holds the original and the local tree is a cache."

The initiative under this page type quoted one intent line after this review, "Every wallpaper file on the workstation has a page, or has been ruled disposable." It did not quote the inversion and its sequence did not mention it. Alan ruled the three `sophia` initiatives obsolete later the same day and they were deleted, their intent lines left standing on the documents that state them, so nothing is aimed at either line now.

Counted the same day: 50 PNGs under `~/Pictures/Wallpapers/Personas` against 44 pages under `instructions:pages/persona-wallpaper/`.

Not measured: which store the install path actually reads from today, whether anything prunes the object store, and whether the Design line still describes what the code does. The two documents were read; the wallpaper writer was not.
