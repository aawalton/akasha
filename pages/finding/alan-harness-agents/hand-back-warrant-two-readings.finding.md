# Claim

The first clause of the Hand Back warrant, "Each further item is owed by some other rule", reads two ways. It resolves to *another rule is where that item's duty lives, so it comes round again*, but it first lands as *another rule requires it, so deliver it* — the opposite pull. The second clause, "a turn is cheap while his attention is not", carries the whole warrant on its own. The corpus writes "X is owed <a thing>" or "owed to <party>" elsewhere, never "owed by <a rule>".
