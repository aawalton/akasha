# Claim

Reviewers land review commits under the default message. `review-instructions` says to land each decision as its own commit and says nothing about what the message should carry, so a commit reads "instructions: edit <path>" rather than naming the decision it holds. Readings dispatched on 2026-08-11 and 2026-08-12 keep reporting it, one for both its commits.

# Evidence

Self-reported by two dispatched `review-instructions` seats, each naming it as a departure from the convention the sibling reviews follow, and each having already pushed to main. Both recorded the account in their report instead.

Not measured: how many review commits across the corpus carry a default message, and whether the convention is written anywhere a reviewer reads.
