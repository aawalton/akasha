# Definition

- **Graph edge iOS app native shell** — the edge from an iOS app to the code its shell is built from.

# Design

The edge lands on the package standing at the stated path, on the file standing there where none does, and on each file under that path where neither does.

Every path the edge is drawn from is stated on the app's own page, so a file the shell build reaches roots only once the page says so.
