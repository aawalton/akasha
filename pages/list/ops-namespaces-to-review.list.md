# Definition

- **Ops namespaces to review** — the ops namespaces holding a command nobody has ruled on.

# Design

The order is by how many commands a namespace holds, fewest first.

A command standing under no namespace is not on this list.

# List

- **service** — 3 commands.
- **tower** — 8 commands.
- **pipeline** — 18 commands.
- **seat** — 30 commands.
- **persona** — 38 commands.
- **instructions** — 42 commands.
- **temper** — 74 commands.
