# Definition

- **Page query times** — the points in time a page query can name.

# List

- **now** — the moment the query is answered.
- **eso-day** — counted from six in the morning, New York.
- **eso-day-next** — the eso day after the one the query is answered in.
- **wake-day** — counted from the moment Alan wakes.
