# Definition

- **Idle live seat** — a seat whose process is live and whose work has stopped.

# Design

Whether a seat states an assignment says nothing about whether it is idle.

A transcript's modification time moves when no work has been done.

The only licence to stop a seat holding no initiative row is a claim carried on its own last send.

A seat can end its turn having narrated an act it never took.

# List

- **Task never ending** — the seat's task names no initiative status, so nothing observable ends it.
- **Initiative outliving its work** — the seat reads its dispatched initiative as running while its file still stands.
- **Sign-in expired** — the last words are a request to log in again.
- **Silent partway** — the seat fell silent short of hand-back, so what it states is honestly unfinished.
- **Stop announced and never run** — the seat said it was stopping, and the command that would stop it never ran.
- **Held by a live child** — the work reads finished, and a child resident for its own reason is read ahead of that.
