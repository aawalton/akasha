# Definition

- **Ops exercise session-finish** — stamping a session completed, appending notes, and reporting its duration and volume.

# Help

Finish a session: stamp completedAt now and optionally append --notes. --session defaults to the most recent open session. Prints the session id and its duration in minutes.
