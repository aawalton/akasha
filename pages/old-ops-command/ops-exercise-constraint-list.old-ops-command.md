# Definition

- **Ops exercise constraint-list** — listing the coaching constraints, filtered to one focus tag and by default to the active ones.

# Help

List active coaching-constraints, sorted by sortOrder. Pass --focus to keep only constraints tagged for that focus (or the universal 'all' tag). Pass --all to include retired (inactive) constraints.
