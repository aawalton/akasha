# Definition

- **Ops exercise history** — one exercise's recent logged sets, newest first, with the heaviest of them named.

# Help

Recent logged sets for an exercise, newest first (date, setNumber, reps, weight, rpe), plus a "best" line — the max weight over the fetched window, ties broken by max reps at that weight.
