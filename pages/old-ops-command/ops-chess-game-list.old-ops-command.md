# Definition

- **Ops chess-game list** — the stored games, most recently played first, narrowed by handle, source, outcome or collection.

# Help

List chess games, most recent first. Filter by --handle, --source, --outcome, and/or --collection. One line per game: id, date, outcome, result, source, pedagogical label, title.
