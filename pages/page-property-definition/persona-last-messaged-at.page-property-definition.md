# Definition

- **Persona last messaged at** — when Alan last wrote to a persona.

# Design

This is stamped every time Alan submits a prompt in a persona's terminal, so it stands beside her page rather than in it.

The persona carrying the newest stamp is the one Alan's wallpaper follows.
