# Definition

- **Domain required reading slugs** — the other domains a domain's readers must have read.

# Design

A domain's required reading holds slugs and no text of its own.

A term is named for its kind, whatever folder it stands in.

A domain may name one below it in the tree.

A domain's required reading names only the terms a reader would misread it without.
