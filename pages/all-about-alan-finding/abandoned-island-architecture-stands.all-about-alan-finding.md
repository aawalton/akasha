# Claim

The off-grid architecture the solar project abandoned still reads as live in the files leading into it. `scope.md` records the pivot: the grid-as-seasonal-battery framing was wrong, the February credit reset kills it, PV is now sized to annual load. `energy-demand.md` still declares self-sufficiency the sizing target and asks 2× PV with 250–500 kWh of battery; `self-sufficiency.md` still closes on 60 kW PV, 300 kWh and a propane generator; `sizing.md` still opens "The grid is the seasonal battery".

# Evidence

Read 2026-08-16 across the 41 files of `all-about-alan/projects/solar-power`.

The pivot, `scope.md`: "The initial framing of 'grid as seasonal battery via net metering' was wrong for Provo Power's current rules"; "**Annual February reset, credits zeroed, no rollover, no cashout.** This eliminates the seasonal-battery mechanic. Oversizing PV beyond annual load is forfeited"; "**PV sized to roughly annual load** — not oversized."

What still stands. `energy-demand.md`, first paragraph: "Sizing target: **self-sufficiency, not financial efficiency**". Its close: "The defensible self-sufficiency architecture for Provo is: **oversize PV ~2×, install ~1–2 days of battery (~250–500 kWh usable), accept that 1–2 weeks per winter will need generator backup**."

`energy-demand/self-sufficiency.md`, "Summary recommendation": "**~60 kW PV** … **~300 kWh usable battery** … **24 kW propane standby generator + 1,000 gal buried tank**. **Wood stove** … This architecture meets the **self-sufficiency goal** … Per Alan's brief, self-sufficiency wins."

`sizing.md`, the index carrying the current planning case, opens: "The grid is the seasonal battery: twelve-month production ≥ twelve-month consumption is the target." Its next sentence points at the pivot — "See scope.md for the architectural pivot away from the pure-island case" — while the sentence before states the framing the pivot removed.

One is marked, in `scope.md` alone: "The previous self-sufficiency-island analysis in [energy-demand/self-sufficiency.md] is reference only — over-scoped for both the original … and the revised … goal." `energy-demand/self-sufficiency.md` carries no such mark itself, and neither does `energy-demand.md`, the index a reader reaches first.

Not measured: I did not check git history, so I state which text stands, not which is newer. `scope.md` is the only file naming itself the correction, and I took its word for that.
