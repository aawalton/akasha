# Intent

- Every secret a service reads is a secret page in akasha.
- A cluster secret is assembled from the secret pages that place a value in it.
- A pod reads no key that no secret page places.
- A secret reaches the cluster without being written to disk.
- No secret is minted in the cluster.
- No secret file sits outside the pages system.
