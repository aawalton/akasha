# Match

- **from** is
  - `noreply-lcr@mail.churchofjesuschrist.org`
- **subject** does not contain
  - `youth`
  - `young women`
  - `young men`
  - `yw `
  - `ym `
  - `primary`

# Rule

**Archive a broadcast asking for volunteer labour; surface the rest.**

Service sign-ups are archived; activities, socials and anything dated he might attend stay his. One sender carries both and no condition separates a labour ask from an invitation.
