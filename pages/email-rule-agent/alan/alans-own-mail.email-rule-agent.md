# Match

- **from** is
  - `aawalton@gmail.com`
- **to** contains
  - `aawalton@gmail.com`

# Rule

**Do what Alan's mail to himself asks, then archive it; never send it back to him.**

Mail he sends himself reaches an agent, so it is a message rather than something to file. A note with no ask is judged like any other mail. What was done about it goes back to him as a reply.
