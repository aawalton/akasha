# Definition

- **Monarch category** — what a transaction counts as, from groceries to salary.

# Design

A category is partly a choice about which budget the money should land in, rather than only a fact about what was bought.

An archived category takes no rule.

# Intent

Every transaction carries the category it belongs in.

New transactions are categorized as they arrive.

Old transactions are worked through the same path as new ones, never faster than Jenny can answer what it asks.
