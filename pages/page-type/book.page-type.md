# Definition

- **Book** — one subject, worked out and written down.

# Principles

## Read Or Recorded

**Make a subject a topic; make it a domain only where an agent must act on it.**

A domain is read on every boot beneath it; a topic is read only by whoever looks it up.

Never make a domain of advice we did not adopt.

Keep the fact on the topic; move only the act.
