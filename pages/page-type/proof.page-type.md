# Definition

- **Proof** — one attempt at deriving a proposition, written by Alan's own hand.

# Design

A proof's derivation stands in its body, never in a value beside it.

A proof names the proposition it attempts; the proposition names no proof.

A superseded attempt stays, and a later attempt is a new proof rather than a rewrite.
