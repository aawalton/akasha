# Definition

- **Persona points source** — the thing a persona's points are counted from.

# Design

A persona's source is settled in a document of her own.

Some sources the engine works out from the rule alone; others name a writer that computes them elsewhere.

A marker names a kind of source rather than whose it is, so several personas may declare one.

# Intent

Every earning persona's document carries the rule naming her source.

The engine can read every source a persona's document names.
