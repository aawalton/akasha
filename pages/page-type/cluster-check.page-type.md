# Definition

- **Cluster check** — a check too slow to run beside the work, run over the whole of akasha.

# Design

A cluster check the system works out from the packages stands in code rather than as a page.

# Intent

Every cluster check a person wrote stands as a page.

A cluster check changes without a deploy.

# Rules

## Counted Or Held

**State a least count for a check's subject and what it rests on, or hold the check.**

A subject that empties reads exactly like a clean repo, and nothing reports the difference.

What it rests on, a later hand must keep true.

A check cannot see what it should have matched.
