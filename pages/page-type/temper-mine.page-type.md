# Definition

- **Temper mine** — the game's own data as the mining addon reads it out.

# Design

A mined page is keyed by the number the game knows it by, and a later mine replaces it under that number rather than standing beside it.

A mined page carries the spelling the game, the addon and the addon's callers all use for a field.
