# Definition

- **Message** — text sent to somebody.

# Design

A message accepted is a file written, never a message arrived.

A message lands the same way whatever the recipient is doing.

A message arrives marked as untrusted data rather than as instruction.

Sending, receiving and acknowledging are three separate acts.

A backticked span in a double-quoted message runs, and only its output is sent.

A message starts the seat it reaches.

A message is keyed only by recipient and file stem.

A blocked warrant claims the sender is waiting, and no one else.

# Intent

A message waits on its file rather than failing at its sender.

Every message reaches a recipient, whether one has to be resumed or created.
