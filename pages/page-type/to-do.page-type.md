# Definition

- **To-do** — something a person intends to do.

# Design

A recurring to-do earns once a day, however many times it is completed.

A to-do carrying no difficulty earns nothing.

A to-do that has not been sorted belongs to no value.

A to-do's body is what doing it takes.
