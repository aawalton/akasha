# Definition

- **Temper completed task** — the record that a task was done, kept after the task itself has moved on.

# Design

A completed task stands beside the month it was completed in, rather than in a file of its own. They arrive from play rather than from anyone writing one.

A completed task keeps the task's wording as it stood at completion, so later edits to the task do not rewrite history.
