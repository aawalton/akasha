# Definition

- **Initiative** — work that closes gaps between how a domain is and how it should be.

# Design

An initiative stands under another initiative, or under none.

Work too big to close in one initiative is done as several beneath one, and is no kind of its own.

An initiative takes each intent off the domain that held it, and holds it as its own text.

An initiative is not limited to one domain.

An initiative's name is its persona and its target domain.

An initiative's purpose is done once every intent it holds is met.

An initiative's notes do not hold it open.

# Condition

An intent is written on a domain or on an initiative, never both.

No initiative holds an intent that is met.

No initiative states a step that is done, in its Sequence or its Notes.
