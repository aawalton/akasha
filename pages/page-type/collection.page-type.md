# Definition

- **Collection** — something for a person to experience.

# Design

A collection's parts are themselves collections.

A collection can be part of more than one collection.

No collection is part of itself, however far the chain runs.

A collection's position is the same in every collection it is part of.

A collection's own lengths are counted in its own unit, and everything summed across its parts is counted in words.

# Intent

No collection counts as part of a larger collection twice.
