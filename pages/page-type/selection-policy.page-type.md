# Definition

- **Selection policy** — the numbers the coach picks and bounds a session by.

# Design

One page carries them, and there is never a second.

# Intent

Every number the selector weighs by stands on this page, and none of them stands in code.

A number missing here stops the selector rather than being supplied from somewhere else.
