# Definition

- **Category rule merchant** — who or what a transaction was with, read out of the words it carries.

# Design

How the money moved is a merchant here, for rows whose words name no vendor.

# Principles

## The Words That Survive

**Take a merchant's patterns from the bank's own text rather than from Monarch's title.**

A title is Monarch's rewrite of the bank's line and changes without warning; the line never does.

Never add the title as an extra pattern.

Copy the run exactly, abbreviations and all.
