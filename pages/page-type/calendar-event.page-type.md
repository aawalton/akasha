# Definition

- **Calendar event** — something at a set time a person might go to.

# Design

The word "primary" names Alan's calendar, never the caller's own.

Reads and deletes act as a service account, and creating, changing and replying act as Alan.

# Intent

A calendar event stands beside the source that publishes it, rather than in a row.
