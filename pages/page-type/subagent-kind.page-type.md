# Definition

- **Subagent kind** — everything a subagent is, apart from the work it is given.

# Design

Any number of subagents can run from one kind at once.

A kind's prompt is the whole of what its subagent starts with.

A kind's definition is what a seat reads to choose between kinds.

The name a seat dispatches by is a property rather than the title.

A kind whose model is unstated runs on the seat's.
