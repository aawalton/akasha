# Definition

- **Gmail processed message** — one message a mailbox has already been through, and what was decided about it.

# Design

A message is written here once it has been decided, so a second pass over the same mailbox skips it.

# Intent

A gmail processed message stands beside the mailbox it was read from, rather than in a row.
