# Definition

- **Wake daily tracking** — what was measured about one of Alan's wake days.

# Design

A page carries the day its waking falls in as its label, and never the boundary itself.

A wake day runs from one waking to the next, so it spans two adjacent ESO days.

Reading one wake day opens both ESO days it spans, and never more than two.
