# Definition

- **Proposition** — one statement in the formal system Alan is building, either adopted or waiting to be proved.

# Design

A proposition's statement stands in its body, never in a value beside it.

An adopted proposition is chosen rather than proved, and carries no proof.

Which proofs attempt a proposition is read from the proofs, never recorded on the proposition.
