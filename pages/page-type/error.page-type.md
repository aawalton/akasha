# Definition

- **Error** — every time one product broke the same way, gathered as one thing to fix.

# Design

What makes two breakages one error is the fingerprint, never the message.

How many times it has happened and when it last did are written on every occurrence, so neither is committed.

Only a 404 says no error page stands; any other unread answer leaves its tally unknown.

An error whose fix was deployed reopens when it breaks again, and every other status stands.

An occurrence is patched onto its page, so every value it does not state survives.

A burst undercounts one fingerprint's tally.
