# Match

- **from** ends with
  - `google.com`
- **subject** contains
  - `oak.hills.first.ward.tech`
- **from** is
  - `googleplay-noreply@google.com`
- **subject** does not contain
  - `your google play order receipt`
  - `privacy`
  - `policy`
  - `terms`
  - `user agreement`
  - `upcoming changes`
