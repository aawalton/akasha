# Match

- **from** ends with
  - `amazon.com`
- **from** is not
  - `store-news@amazon.com`
- **subject** contains
  - `ordered:`
  - `shipped`
  - `out for delivery`
  - `arriving`
  - `delivered`
  - `dropoff confirmed`
  - `return request confirmed`
  - `advance refund issued`
  - `saved additional money on your amazon pre-order`
