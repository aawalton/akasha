# Match

- **from** ends with
  - `churchofjesuschrist.org`
- **subject** contains
  - `youth`
  - `young women`
  - `young men`
  - `yw `
  - `ym `
  - `primary`
- **from** is
  - `noreply-finance@mail.churchofjesuschrist.org`
- **subject** does not contain
  - `statement`
