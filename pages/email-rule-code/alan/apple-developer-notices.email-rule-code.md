# Match

- **from** is
  - `no_reply@email.apple.com`
  - `testflight_no_reply@email.apple.com`
- **subject** contains
  - `completed processing`
  - `is now available to test`
- **from** is
  - `no_reply@email.apple.com`
- **subject** does not contain
  - `your receipt from apple`
