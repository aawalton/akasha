# Definition

- **Ops exercise policy-show** — the selection policy's weights and tunables, every one of them read from its page.

# Help

Show the selection policy — the four goal weights (Longevity / Energy / Functionality / Aesthetics) the scorer blends by, plus the session and volume tunables. Every number it prints stands on the page; nothing is supplied from code.
