# Definition

- **Ops exercise schedule-create** — replacing the active weekly schedule with a new one and its seven schedule-days, one per day flag.

# Help

Create the weekly workout schedule: one workout-schedule page (active) plus 7 schedule-day children, one per day flag. Any currently-active schedule is deactivated first — exactly one schedule is active at a time. Focus options: push | pull | legs | upper | lower | full-body | core | conditioning | flex | rest.
