# Definition

- **Ops exercise equipment-list** — every equipment item in sortOrder, owned only or, under `--all`, the proposed ones too.

# Help

List equipment items (available implements + load increments), sorted by sortOrder. By default shows owned items only — pass --all to include proposed/future (unavailable) implements.
