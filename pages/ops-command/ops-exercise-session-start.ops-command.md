# Definition

- **Ops exercise session-start** — opening a session for one day from the active schedule, after closing the abandoned ones.

# Help

Start a workout session for today (or --date). Resolves the active schedule's day for the date to derive the focus; --force allows starting on a rest day. Prints the session id.
