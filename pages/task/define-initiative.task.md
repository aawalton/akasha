# Definition

- **Define initiative** — opening one initiative against a domain, and the intent it quotes.

# Sequence

1. **The end every gap is measured against.**
   - **Settle** what finished looks like before measuring anything against it, taking whatever the domain's `# Intent` already states and authoring the rest onto the initiative. A stale end is worse than a missing one: the gaps get measured against the wrong thing, and nothing says the end itself was wrong. An end written only to get past this step hands every intent a guess to measure against.
   - **Write** nothing onto a domain that this initiative will carry away again. A domain is where an intent waits for an initiative, never somewhere one passes through.

2. **Whether to open it at all.**
   - **Open** nothing where settling the intent closed the gap the initiative was for, and say so instead. An initiative written anyway measures a distance of zero.
   - **Open** several standing under one where the gap is too wide for a single initiative to close, and keep on the one above only the lines no single initiative beneath it closes. An intent a single initiative closes belongs on that initiative, where the seat carrying it can read it without opening anything above.
   - **Name** the wider initiative in this one's `parent-slug:` key where one already stands over the gap. Nothing else records the edge: an initiative lists nothing standing beneath it, so one left unnamed here is work its parent cannot see.

3. **The initiative's `# Intent` — what would make it finished.**
   - **Move** each intent the domain already states onto the initiative, deleting it from the domain in one write. A line left in both places drifts, and the copy a reader opens first is the one they work to.
   - **Present** the whole proposed set at once, in the order you expect to close it, and write it onto the initiative in that same order. Every line reached Alan already, one at a time, as it landed on the domain, so what is still open is which of them this initiative carries and which it does first.
   - **Choose** the set so that meeting every intent in it is what satisfies Alan, and never add a line to the domain's `# Intent` asking for his judgment so that you can quote it last. Such a line is always easy to write and always sounds reasonable, but it moves the standard out of the set, leaving the rest to be closed by instrument alone.

# Invariants

- **Alan settles what the document says and you write it down.** Where his account leaves a gap, ask rather than closing it from what you saw yourself: a gap you filled reads exactly like one he stated, and what comes back is your framing with his agreement on it.

- **An initiative standing beneath another is opened after it, never beside it.** What the one above quotes is what those beneath are drawn from, so one opened in the same run is drawn from a set nobody has ruled on yet.
