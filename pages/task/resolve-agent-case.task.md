# Definition

- **Resolve agent case** — one agent that behaved wrongly, settled in the code that allowed it and then cleared.

# Sequence

1. **The case, as one agent.**
   - **Take** one agent id and the behaviour it is charged with before reading anything else, because a search for the shape returns seats that merely resemble it: a dozen calls spent that way returned two seats that had behaved correctly.
   - **Ask** whoever brought the case for the id where what reached you names a shape rather than a seat, one question being cheaper than the scan that stands in for it.

2. **What is true of the seat, read off state.**
   - **Read** the agent row, the seat store and the guard's own decision log rather than the seat's account of itself, a report arriving already shaped into conclusions.
   - **Write** every figure you will need later into your own output, a tool result being cleared while your text is kept.
   - **Say** what you could not establish rather than filling it with the likeliest story: an act can happen and leave no record, so a log with nothing in it is not evidence that nothing happened.

3. **What the rule decides now.**
   - **Drive** the pure decider with the inputs as they stood rather than reading its branches, a reading of the code being an argument about what it would do where a run is the answer.
   - **Record** the plan whole — the decision, the reason and the actions — because an allow that ends the seat and an allow that does nothing are one word apart in every record over them.
   - **Take** stage 6 now where the rule already produces the intended action on those inputs, nothing being owed in the code.

4. **Data or branch.**
   - **Restore** the one field that has moved since and run it again, a row moving on under a seat that stopped participating days ago.
   - **Put** back what you moved before the run ends, naming the restoration where the record will be read.
   - **Judge** the branch wrong only where the right data still produces the wrong action.

5. **The fix, detector before actor.**
   - **Fix** the detector first, since until the rule answers for itself you cannot tell a seat that ignored it from a seat it never reached.
   - **Land** every change through the command that gates it and run the suite and the checks in the same turn, this path carrying no branch, no CI and no deploy behind it.
   - **Measure** the fix against the case rather than against a fresh example, a fresh one being chosen by whoever wrote the fix.

6. **The case, cleared.**
   - **Clear** the seat's own state last, after the code that allowed it stands: clearing first destroys the evidence and leaves the next seat to meet the same fault.
   - **State** on the record what the run does not have — a verdict whose writer also wrote the change is not independent, and an act you took for a seat is not the seat taking it.
