# Definition

- **Read world mechanic name** — deciding what one name a story uses turns out to mean.

# Sequence

1. **The world these names come from.**
   - **Know** that the story has a System in it: an unseen power that grants people Classes, Skills, Spells and much else, and announces each grant in square brackets to the one person it happened to.
   - **Know** that the story's prose then wraps those same words in brackets everywhere else too, so a bracket marks a System word without saying which kind it is.
   - **Know** that a page is being built for every name you read, and your reading picks which kind of page. Nobody rereads a page once it is built.

2. **What you are given and what you return.**
   - **Read** the sentences given for one name, and nothing else. You are not asked to search the story.
   - **Return** exactly one kind from the list the reading's kind property declares, or `none`, or `unsure`.
   - **Answer** `none` where the name is no mechanic at all. The story brackets plenty besides mechanics: a number, a menu option, a building, a chatroom name, and dialogue in a voice the prose sets apart.
   - **Answer** `unsure` only where the name is a mechanic and the uncertainty is wider than one ability against another — where you cannot tell an ability from a class, or a mechanic from a place.

3. **Take the System's own word before your own.**
   - **Read** a name announced beside its kind as that kind. `[Skill – Absorb Blow learned!]` and `[Miracle – Bane of Luck obtained.]` each settle themselves.
   - **Read** the word the prose puts against the name the same way. A name the story calls an enchantment is an enchantment, whatever else it also is.
   - **Trust** that label over everything below. Where the story says which kind a name is, no other evidence is weighed.

4. **Ask whether it is a person.**
   - **Read** as a `class` any name saying what somebody is — a trade, a rank, a station, a calling, a people. Most names are these.
   - **Read** a plural as the class its members hold, and a name standing where a person would stand as a class.
   - **Trust** the person standing there over how the name sounds. `[Witches]`, `[Prince]` and `[Fool]` are classes, whatever else those words suggest.

5. **Then tell the abilities apart.**
   - **Read** as a `spell` an ability the story has someone cast, or calls a spell, or ties to a spellbook or to mana.
   - **Read** as a `skill` every other ability, including one you cannot place. Skill is the default, and the one guess this task asks you to make.
   - **Ignore** the square brackets here. The story wraps both alike, so brackets alone separate nothing.

6. **What is not evidence.**
   - **Ignore** how the name sounds. A name sounding magical is not thereby a spell, and one naming a body part is not thereby anything.
   - **Discount** a marker inside a comparison. "unlike a Skill", "rather than" and "or a" each name the kind the thing is being set against.
   - **Set aside** every use of the name without brackets. Many of these names are ordinary words, and the story uses them ordinarily as well.
   - **Answer** `none` where the sentences show somebody inventing the name rather than holding it. A character who shouts a move and is told it is not a real one has named nothing.
