# Definition

- **File finding** — recording one observation about a domain where it will be read.

# Sequence

1. **Whether it is a finding at all.**
   - **File** what you noticed rather than writing it into a document that is not about it. In the moment it feels more responsible than filing.
   - **Leave** out whatever you repaired in the same breath. A defect you fixed is a commit; a finding is what you are deliberately not acting on.
   - **File** it even where you suspect it is already known. Checking costs more than the duplicate does.
   - **Send** a message instead where something must happen now. Filing decides nothing and starts nobody.

2. **The finding itself.**
   - **State** the claim as something that is so and never as an action to take. A lead reads the claims across a domain to find the pattern, so one written as a task to do hides the very thing the findings store exists to show.
   - **Say** under evidence what you did not measure. A finding that says nothing about its own limits is read as having none.
   - **Land** it through `ops finding create`.
