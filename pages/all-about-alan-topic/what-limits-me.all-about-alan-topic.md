# Definition

- **What Limits Me** — the one resource holding everything else up.

# Design

It is one at a time, and which one it is changes as I recover.

# Questions

Which years executive function held the bottleneck is unrecorded, and so is when each restorer took effect.

The stress signal I tracked for twenty years may only ever have been a proxy for safety, which would dissolve the account of the bottleneck passing rather than confirm it.

The limiting resource already moved once, from stress to safety, and the hub moved with it. Is it fixed at safety now, or can it move again, and what would move it?
