# Definition

- **What A Model Leaves Out** — what every model costs to be usable, and where I think the value actually sits

# Design

All models are false, because they simplify out nuance for intelligibility.

I find the nuance is where the gold is.

# Questions

This sits against my own test that a model has to fit in my head before it changes what I do, so concise beats complete. Which way I go when the nuance will not fit is unsettled.

Abby's reading: this is why every topic in this book carries a Questions section. The section is where the nuance a definition simplified out gets kept instead of thrown away.

Whether some nuance is worth losing, and what tells me which, is unprobed.
