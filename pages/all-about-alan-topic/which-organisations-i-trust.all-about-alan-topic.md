# Definition

- **Which Organisations I Trust** — the test an organisation has to pass before I will rely on it

# Design

Decades of track record, plus visibly refusing to yield when pushed.

Stated values are not evidence. Only behaviour under pressure counts.

Everyone is being tested right now, so recent behaviour carries the strongest signal and nobody is grandfathered.

If I cannot trust them to survive I cannot trust them, so stability sits on the same axis.

# Questions

When every trusted organisation fails at once, whether to hold the decades line, weight resisting years heavier, or run two tiers, is open.

Signals beyond resisting behaviour, of ownership, worker treatment, transparency and governance, are unenumerated.

Whether the duration condition relaxes for co-ops and member-owned bodies, structurally insulated from the pressure, is open.

Whether this, how a person earns my trust and how I ground a belief all run on one mechanism is open.
