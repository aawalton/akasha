# Definition

- **The Modes I Run In** — the different ways I can run, and what each of them costs to hold

# Design

Robot mode is one of them: a state I drop into rather than a way of describing me.

# Questions

Whether running robot mode saves capacity or costs more than the masking it replaces is unknown, and when I reach for it is unrecorded.

Whether it and the conceptual provision I run in my marriage are one system or two has never been settled.

Whether my resource state decides which mode is even available is unexamined. Low mana pushing me further onto the harness, and low safety degrading my physical responses, are both proposed and untested.
