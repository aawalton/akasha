# Definition

- **Which Lever Reaches A Response** — the two kinds of learned response in me, and which remedy fits which

# Design

One kind runs through a belief. Rewrite the belief and the behaviour changes on the next go.

The other fires before any thought loads, so understanding it does nothing at all.

A won argument does not switch off a rule running below it. Five of mine still fire.

No framework moves me until it yields a concrete use that lands in my map.

For the below-thought kind I expand only on a surplus and re-ask whether it is safe now, holding dangerous provisionally true.

# Questions

Some responses are part belief and part reflex. Which lever to reach for first, and whether rewriting the belief lightens what exposure has to do, is open.

Whether a reflex can quiet enough that thought arrives in time and it becomes belief-reachable, or only ever stays reflexive and quieter, is unanswered.

I cannot tell a true social cost from an inflated one from inside, and nothing reads it before I act. Whether the re-test after can ever be skipped is open.
