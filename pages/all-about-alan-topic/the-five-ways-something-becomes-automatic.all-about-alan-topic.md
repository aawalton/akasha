# Definition

- **The Five Ways Something Becomes Automatic** — the five different systems that can make a thing automatic in me

# Design

They are sensory habituation, picking things up socially without trying, a response fired by an outside cue, fitting new things into what I already know, and running a sequence of actions as one.

# Questions

Where my compensations are described they still run on an older two-way split, so which of the five each actually uses is unassigned.

Memorising text, giving a talk and the harness itself all look like the outside-cue one. Whether that is one system doing three jobs is unconfirmed.
