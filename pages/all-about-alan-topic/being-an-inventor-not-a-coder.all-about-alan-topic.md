# Definition

- **Being An Inventor Not A Coder** — what I actually am, against the trade I was raised into

# Design

I am an excellent coder, but that has never been my identity.

I am an inventor and problem solver. Code is just a powerful way to stack abstractions.

I loved the Moore method in math.

One of my proudest moments was inventing a novel algorithm for optimising The Game of Life, in an MS CS program I did for a while.

I am doing the same thing now that I was a year ago, just with literally a hundred times more leverage than I had before.

# Questions

The Game of Life algorithm is named and never described.

The MS CS program is one I did for a while. How it ended is unwritten.

What the Moore method gave me, and whether it shows up in how I build now, is unprobed.
