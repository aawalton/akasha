# Definition

- **Not Reading Code Any More** — what I read now that I do not read code

# Design

I do not think I have read code at all in 2026.

I read docs, because that is where human intervention is most necessary, especially with the domain system.

# Questions

How I would find out if the code stopped matching the documentation it runs off is unwritten.

What reading docs instead of code costs me, if anything, has not been probed. I have only said I do not miss coding.
