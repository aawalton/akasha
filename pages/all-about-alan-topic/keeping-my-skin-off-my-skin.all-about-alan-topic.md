# Definition

- **Keeping My Skin Off My Skin** — putting something between my own surfaces, because the touch registers twice

# Design

Skin on skin lands on both sides at once, so the signal is delivered twice on a system already paying too much per input.

Any layer breaks it. Sleeves, a shirt, trousers, socks, a pillow between the knees.

Loose works as well as tight here, so swapping to loose loses the grounding and not this.

Posture counts too: not clasping hands, not sitting with the knees together.

# Questions

The highest-cost places have never been anchored concretely.

How this is handled asleep, where the pillow goes and how it sits with the weighted blanket, is unworked.

Whether loose really equals tight everywhere, or some places do better with one, is untested.
