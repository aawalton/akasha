# Definition

- **Noticing What She Needs** — the doing works, and what fails is seeing that something is wanted.

# Design

Asking instead of guessing is the one bridge I have built, and it does not run consistently.

Recall does not fire unprompted, so responding depends on effort rather than on a default.

# Questions

The shared diagnosis is agreed and the bridges are not built. Each blocked piece still needs its own.

Whether a does-this-touch-her check belongs in my decision rules, as the trigger the asking needs, is open.

Whether a default path can be installed at all, or whether responding only ever runs on surplus, is unsettled.
