# Definition

- **The Foods I Can Still Manage** — the small set that holds when all four bars are low

# Design

A food has to be bland, quick, dense and safe to finish. Nothing is in the set for pleasure.

There is no rotation. I take whichever one is reachable in the moment.

At crisis-low the dishware goes disposable, so cleanup costs nothing.

The muesli I found in Russia at twenty is my one reliable self-started meal, and it works every time.

At two or below there is nothing in my room I can get myself to eat, because the wanting has to fund the reaching.

# Questions

How the upstream prep gets kept up, when that maintenance is invisible exactly when the set is needed, is unworked.

The full set, how foods have entered and left over the years, and what admits a candidate, is unprobed.

Whether letting the cleanup go at crisis-low generalises to laundry, messages and projects is open.
