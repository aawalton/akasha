# Definition

- **The Five Rules I Grew Up With** — the five rules I learned as a child that still fire, long after I stopped believing them

# Design

Always be nice, always be quiet, do not take up space, do not ask for anything, take care of yourself.

They run from below thought, so winning the argument against them did not stop them.

# Questions

What founded each one, and whether they have five separate origins or one shared type, is open.

What each still costs me now, and how tight its grip is, is unmeasured.

How to retire one is unworked, and this is where a disbelieved reflex still firing bites hardest.
