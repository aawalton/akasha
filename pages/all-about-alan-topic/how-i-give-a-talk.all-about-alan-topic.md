# Definition

- **How I Give A Talk** — carrying a set of small points that fire when the room calls for them, rather than a script

# Design

Nothing is memorised word for word, so there is nothing I depend on remembering.

Each point is small and paired with the circumstance that should fire it, and the order comes from the room.

Thinking broadly first is what keeps the set from running out when the talk goes somewhere I did not expect.

It costs me exact phrasing and some working memory during the talk, and saves me all of the recall.

# Questions

How a point gets built, added, dropped, split or merged has never been described.

How many I carry for a talk, and how that scales with the breadth of the topic, is unrecorded.

With rehearsal off the table, what stands in for it, running the set or anticipating the room or both, is unsettled.
