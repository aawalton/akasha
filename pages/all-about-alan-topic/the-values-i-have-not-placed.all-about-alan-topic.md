# Definition

- **The Values I Have Not Placed** — fun, wealth and the rest of what I run on, none of them ranked or pointed at a part of me

# Design

Only the top four of the six are pointed at a part of me.

The six were set before the wider set of things I run on existed.

# Questions

Where fun sits is unresolved: which part of me it improves, whether it feeds the top three the way learning does, and why it ranks under health.

Wealth has never been glossed at all, including which part of me it improves.

What I run on now is wider than the six, and how the whole set orders, including where identity sits, has never been recorded.
