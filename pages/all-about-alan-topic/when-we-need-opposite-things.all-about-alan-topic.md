# Definition

- **When We Need Opposite Things** — one room set the way she needs it and against the way I do.

# Design

Light steadies her and drains me. I defer to her by default and override only when I am really not doing well.

The cost is paid the whole time the arrangement runs, not once when we set it.

# Questions

Whether sound, temperature and scheduling settle the same way, deferring by default with an override underneath, is unprobed.
