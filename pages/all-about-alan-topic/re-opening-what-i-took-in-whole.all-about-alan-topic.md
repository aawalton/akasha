# Definition

- **Re-Opening What I Took In Whole** — going back over beliefs I absorbed without ever examining them

# Design

My rigidity lets an idea in whole and unexamined, so I learned to go back over ones already in me.

The gate is evidence, never motive. I cannot hold a belief because it suits me.

That is what made granting myself an accommodation honest. A false I-cannot would not survive what I can plainly do.

The block was internal. Whether anyone else could see the disability had no bearing on whether it was real.

I run the same move on my faith, discounting myself for having been raised inside it.

# Questions

What sets off a pass over an old belief, and how I choose which ones to re-open, is untraced.

Whether this is the same operation as digging a belief up and rebuilding it, or the earlier step that decides one needs digging up, is unsettled.

Whether I cannot build a false belief at all, or only cannot hold one against my own truth-detector, is unsettled. The holding end is unprobed.
