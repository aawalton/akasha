# Definition

- **How I Pick A Sensory Tool** — the order I want one in, from adjusting itself down to nothing at all.

# Design

A tool that matches the dose to the load beats one that forces on or off, even though working it takes something from me.

I adjust a tool while it runs, on a live signal, whatever its cost shape: an AirPod part out, clothes broken loose, the blanket swapped mid-sleep.

# Questions

Touch and taste have never been read against this order, so the tools there are unplaced.

Whether the effort of working a tool always pays back in capacity saved, or only above some load, is unsettled.

Automatic tools that misjudge cost more than manual ones. Which of mine fail, and when, is unprobed.

Whether the order maps onto regulating myself from the inside is open. Arousal already does not.
