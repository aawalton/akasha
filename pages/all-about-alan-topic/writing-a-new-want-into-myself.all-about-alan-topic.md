# Definition

- **Writing A New Want Into Myself** — the wants I install in myself, as against the ones that came with me

# Design

The given ones fire as desire or as irritation: hunger, loneliness, needless complexity. The rest I wrote in.

Nearly all the written ones serve something else. Improving myself is the one I want for itself.

I cannot install one by deciding to. It has to reach me from where I put it, in what I let myself see.

# Questions

What writes a new measure into the map, what makes one stick, and whether writing one is itself a want, is open.

Whether a measure can be retired at all, or only ever have its triggers managed, is unprobed.

One prediction is untested: a want needing a pre-felt payoff should never install, and one that reduces to a present irritant should take.
