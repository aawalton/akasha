# Definition

- **How Stale My Read On A Relationship Gets** — how my read on where a relationship stands goes out of date, and which way it drifts

# Design

The error bars widen as time passes, and the centre stays where she last set it.

# Questions

Whether to re-centre downward by how fast each one decays is unprobed, and with no felt signal there is nothing to estimate the decay from.

Whether an untended relationship erodes by default is assumed rather than established. If it does, widening without re-centring is optimistic by construction, and it bites hardest on the ones gone reactive-only.
