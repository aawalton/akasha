git_mirror_refs_unconfirmed has no series, so nothing is checking whether this system's only off-cluster copies are current. Two possible causes and both need checking: (1) the Prometheus scrape of postgres-exporter dropped, or (2) the hourly probe died — the exporter query only returns rows written in the last 2h, so a CronJob that stopped being scheduled, that is suspended, or that runs and fails silently empties the series within two ticks. Check: kubectl get cronjob git-mirror-probe -n ci and kubectl get jobs -n ci --sort-by=.metadata.creationTimestamp | tail, then the postgres-exporter target in Prometheus.
