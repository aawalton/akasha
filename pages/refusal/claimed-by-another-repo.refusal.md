# Refusal

`{path}` is claimed by the `{type}` page type on the {claimed} repo, through `{glob}`, and this call addresses the {addressed} repo.

Landed here it is held to no shape and reached by no check, both of which run over the repo the page type claims — so it would read as a clean write and be visible to nothing. Put it through that repo's own command instead.
