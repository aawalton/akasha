# Refusal

{path} names `championed-domain-slug: {holds}` and {at} names `persona-champion-slug: {persona}` — one statement made twice, disagreeing.

Each domain names one champion and each champion names one domain, so only one of these can stand. Settle whether {her} or {persona} champions {holds}, then rewrite the end that was wrong; a key removed on the losing side leaves that persona championing nothing, which is allowed.
