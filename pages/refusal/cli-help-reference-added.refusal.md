# Refusal

`ops {command}` names `{token}` in {kind}:{field}, and no command in this surface declares that flag.

Either the flag was retired and this prose still advertises it, or it belongs to another program. Quote that program alongside it and the reference reads as foreign rather than as a promise this surface does not keep.
