# Refusal

Neither `AGENT_ID` nor `CLAUDE_CODE_SESSION_ID` is set, so no read can be attributed to whoever is writing.

This is refused rather than charged to a shared record, which would let one agent's read authorise another's write. Set `AGENT_ID` in this session's environment, or launch through whatever sets it, and read again.
