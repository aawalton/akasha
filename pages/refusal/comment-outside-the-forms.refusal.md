# Refusal

`{path}` would land carrying {count} comment(s) that are none of the code comment forms, at {comments}.

Every form on `{forms}` is a directive some program parses: a compiler, a linter, a debugger or the kernel acts on the line, and taking it out changes what runs. Anything else is prose, and prose in a source file binds Opus 5 as readily as a domain does — while no page type bounds it, no review reaches it, and changing it costs a deploy where a domain line costs none.

Move what it says to a domain, where it is required reading and where a reader looking for what binds this path will find it. `ops domain required-reading --file-path {path}` names the documents that already do.

Where the line really is a directive a program reads, it is a form nobody has written down yet. `{forms}` is where it goes, and Alan rules on each one before it is added.
