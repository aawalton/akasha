# Refusal

`ops {command}` names `{token}` in {kind}:{field}, and no command in this surface declares that flag. It sits inside a code span led by `{span}`, so nothing in that span names a program and this check cannot say whose flag it is.

Lead the span with the program it quotes and the reference reads as foreign, or take the flag out of the prose. Quoting the flag harder does not help: it is already quoted, and what is missing is the program beside it.
