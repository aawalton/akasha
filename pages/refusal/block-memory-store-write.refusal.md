# Refusal

`{path}` is inside a Claude Code memory store.

Nothing in this system reads one, so what lands there is durable state that cannot be reviewed, searched or versioned, and nothing would ever report it.

Anything worth keeping goes in a file its repository carries, written through that repository's own command.
