# Refusal

{path} states `default:` and `required: true` together, and `pages/page-type/page-property-definition.page-type.md` states that a property with a default is not required.

A default is what a page takes where it states none, and a required key leaves no page stating none — so one of the two never comes into play.

Drop whichever of them the key does not want
