# Refusal

Your context was replaced at {when} (`{source}`), which discarded every read you had made, and `{path}` was one of them. Nothing is wrong with the file or with the change you are making; the reading no longer stands because the body it put in front of you is no longer in front of you.

`{route}` prints it whole and records the read again. Then make the change against what it says now.
