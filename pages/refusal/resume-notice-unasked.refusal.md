# Refusal

{asker} holds no `"{key}"` — the name inside double quotes, which is the whole of what this check looks for. Either it asks for a notice this repository does not declare, and the composition fails so every seat put back to work gets a diagnostic in place of its notices; or it has stopped asking for one it does, which fails the opposite way: every seat put back to work is handed one notice fewer, and nothing reports the loss.
