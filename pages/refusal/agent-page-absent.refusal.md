# Refusal

Nothing records what `{agent}` has read, because no page carries that record, so {lapsed}.

This is refused rather than passed over: a guard that stops guarding without stopping the act is worse than no guard, because the act still reads as checked. An agent's readings are an attachment on the agent's own page, so an agent without a page has nowhere for a reading to land, and reading more will not mend it. A seat's page is written by its supervisor while an agent is present in it, and a subagent's when it is made; an agent with neither is not seated and should not be writing.
