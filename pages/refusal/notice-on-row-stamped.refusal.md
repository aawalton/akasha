# Refusal

`{key}` opens with `[supervisor]`. That marks a notice handed to a respawn as its argv, where there is no row to carry a sender. This notice arrives on a message row instead, and a row records its own sender — so the opening is a second copy of something already held, and it tells the seat the notice came by a route it did not come by.
