# Refusal

`{exported}` is exported here and declared in `{source}`.

Forwarding a name buys no boundary. Nothing stops a caller importing `{source}` directly, so the extra door narrows nothing, and it hides that there are two files where the folder reads as one. Import from `{source}` at each call site.
