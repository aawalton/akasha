# Refusal

You have read only part of `{path}` — line {line} onward is unread, so what you are working from is a fragment rather than the file. Reading a range and reading the whole leave you the same sense of having read it, which is how the longest documents end up the least seen.

`{route}` prints the whole of it and records the read. Then make the change against all of what it says.
