# Refusal

`{name}` is registered as `$HOME/{registered}` and the code repository tracks a file of that name at `{path}`. Nothing fires that copy and nothing compares the two, so it drifts from the guard that does fire and whoever reads it cannot tell which of them is standing.

No hook is excepted: every one belongs under `tools/hooks/`.
