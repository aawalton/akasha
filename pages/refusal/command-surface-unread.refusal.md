# Refusal

A command's module would not load, so the surface this was measured over is shorter than the set of commands `ops` carries: {detail}

A short surface is not a clean one. Every command missing from it is a command this check did not look at, and a check that quietly stops looking reads exactly like one that kept passing — so the reading is refused rather than reported over what was left.
