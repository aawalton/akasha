# Refusal

`ops {command}` declares itself irreversible, and nothing on record says you have read its help since that help last changed.

Read it first:  ops {command} --help

A command that refuses a malformed call corrects you at the moment of the mistake, and is not gated here. This one accepts the call, so whatever it lands is landed — the reading is the only thing standing between those two, and it is asked once per version of the help rather than once per call. What moves that version is the help block itself, so a file rewritten without its words changing asks nothing of you.
