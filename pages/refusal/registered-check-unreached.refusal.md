# Refusal

the `check` workflow registers `{path}` and `pages/page-type/cluster-check.page-type.md` is not required reading for it, so whoever writes it is under nothing saying what a check is — neither Removal First nor Zero At Landing nor Dispatch Reach. Move the check into a package whose page reaches that document, or have a document that reaches it claim this exact path.
