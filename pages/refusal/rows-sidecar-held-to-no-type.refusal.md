# Refusal

`{path}` is named as the sidecar holding the `{key}` rows of the page beside it, and {why}.

Nothing settles what its rows would be held to, so every row in it goes unjudged. An unreachable sidecar is refused rather than passed over, because passed over it reads exactly like a file that is no sidecar at all — and a whole sidecar nothing has put a question to would stand as clean.
