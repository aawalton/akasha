# Definition

- **Domain intent** — a domain invariant that does not hold yet.

# Design

Each intent entry names a state the domain should be in, never an act to take or a reason for it.

# Rules

## Resolve When Found

**Move or delete an intent entry as soon as you find it true, not when the work on it closes.**

Nothing re-reads an entry, so one that came true and stayed sends someone at a gap already shut.

Check the whole claim, not just the case you met.

Resolve the entry you found, not the section.
