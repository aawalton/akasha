# Dynamic feedback loop

Current safety level depends on current stress-capacity surplus.

- Optimal surplus: 12 hours.
- Below 12: −0.5 safety step.
- Below 8: another −0.5 safety step.
- ...and so on (the pattern continues).

This is a dynamic system where a high multiplier can quickly escalate: costs drop safety level → multiplier increases → rate of decline increases. (See [stress-capacity-formula.md](stress-capacity-formula.book-chapter.md) for the multiplier table and [recovery-rates.md](recovery-rates.book-chapter.md) for the inputs that restore surplus.)
