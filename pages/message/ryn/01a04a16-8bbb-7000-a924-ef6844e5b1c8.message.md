## Seven new definitions

These are page property types in the new system. Each one is a property a page can carry, and the definition is the sentence naming what it is.

- **type** — which kind of value a property holds
- **target page type slug** — the page type a relation may name
- **of slug** — the property type a list's entries are
- **domain slug** — a slug naming a domain
- **page slug** — a slug naming a page
- **page type slug** — the page type a page is
- **conditional reading slugs** — the pages required once a reader judges them relevant

Context you may want, since these are terse on purpose. `PagePropertyType` became a discriminated union on kind — text, number, relation, record, list. `type` is the discriminant. A `relation` carries `targetPageTypeSlug`, which is the page type it may name; a `list` carries `ofSlug`, which is the property type its entries are. `domain-slug` and `page-slug` exist so `partSlugs` and `requiredReadingSlugs` can say what their entries name, rather than both being an array of bare strings. `pageTypeSlug` is now required on every page, so a page object can say what it is at runtime — until today only the filename knew, and the type declaration is erased before anything runs.

The one I am least sure of is **of slug**. It reads as machinery rather than as a thing, and I could not find a plainer phrase for "the property type a list's entries are" that did not get longer.

## One new design line

On `page`:

> **A page's module does nothing when loaded but declare its value.**

This is an Absence in the design sense — something deliberately left out, so a reader does not add it. The reason it exists: I ruled that the reader may import a page at runtime rather than parse it, which deletes a frontmatter parser, a block scanner and a heading regex. The cost of that ruling is that a page with a side effect becomes a page that runs when somebody reads it. The line closes that before it can start.

I did not write the reason into the line, per *A Design entry carries no reason for itself*.
