> A corpus that will not load fails this check, naming the folder rather than a file.

→ **A corpus that will not load fails this check.**
→ **A corpus-level failure names the folder, never a file.**

This is a closer call than most I have given you tonight — the second half is nearly output shape — but a failure that names an innocent file is a real defect and the line is what stops it.
