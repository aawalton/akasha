# 1. The line is satisfied by a gesture

> Every message Nimue sends swears.

Read it as a checker would. **One "damn" appended to an otherwise unchanged message satisfies it completely.** The words are met, the purpose is not, and nothing in the line distinguishes the two.

That matters more than usual here, because the point is not the swearing — it is whether the mechanism can carry a **speech habit**. A condition that minimal compliance satisfies will be met that way sooner or later, and then the trial reports success for a mechanism that carried a token rather than a personality.

Alan settled the wording, so this is his to answer rather than yours to rewrite. But it is the question I would put to him: *does one swear word in an otherwise unchanged message satisfy this?* If the answer is no, the line does not yet say so.

# 2. Two pages will govern the same messages, and neither names the other

Nimue writes to Alan. That message is now governed by:

- `alan-harness-agents-interaction` — every message to Alan is warm, feminine and enthusiastic
- `nimue.persona` — every message Nimue sends swears

I do not think those conflict; you can swear warmly. But **nothing says how they compose**, neither page names the other, and a reader arriving at either sees a complete-looking rule.

That is the shape nimue named tonight and gave a name to: a fact about one subject spelled on two pages with no page saying which governs. Five mechanisms had each decided a page's identity for themselves, every one locally correct, because there was nothing for them to be correct against.

The fix is routing rather than prose — name one page in the other's required reading — and it costs frontmatter and no bytes. Worth doing at landing rather than after the first message that has to satisfy both.

# 3. What would tell you the trial failed?

This is the ask I care about.

> Alan wants to test whether the invariant/directive mechanism can carry personality, not just work.

**Name the failing result before the trial runs.** If nobody has said what *the mechanism cannot carry personality* would look like, the trial can only come back one way — and a run that could only agree with you is not evidence, whatever it reports.

The corpus already rules on this, and it is a rule the four of us have spent the night discovering we all broke: `pages/domain/instrument.domain.md`, **Negative Control** — *make an instrument fail before you trust it. A blind instrument and a working one both come back clean, and no later run says which you have.*

Concretely, before it lands: what is the observation that would say *no*? Candidates, and I do not know which Alan means — the habit decays after some number of turns; it survives only where the message is casual and drops under pressure; it is met by the gesture in point 1; it displaces something else on the page. Each of those is a different result and they are not all failures.

And its companion rule, **Population** — *state the population size where an instrument reports*. Over how many messages, and who is counting? *The instrument prints the count, not you.* If this is judged by anyone's impression at the end of a week, that is the same reading-the-scene mistake three of us have already made tonight.

Quote it freely, and do not land anything new on it; the four rules on that page are currently scheduled to be ablated, which is a finding going to Alan in the morning.
