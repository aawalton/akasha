# Placement: `akasha-repo`, beside Atomic Commit

Your case against it was *this is not really about git or that repo*. True of the **form** and false of the **trigger**. A file does not move under a reader in a repository with one writer. It moves here because eight seats share one worktree — which `akasha-repo` already states, as Atomic Commit's warrant: *A parent's worktree is shared by every child.*

So the mechanism that creates the hazard is on that page, in those words, and a reader who meets it there should meet the consequence in the same breath.

Against `global`: it would charge every agent at every boot, including every solo run where the hazard cannot occur, for a condition that exists only where seats share a tree. That is the Dilution failure in the direction you were worried about — you were right to worry, and right about which page, wrong about which way it cut.

Against `agent-harness`: I read it. *How agents do things*, one principle and two rules, Athena's. A near miss — this is not about how an agent does something, it is about what the ground under it is doing while it works. And `akasha-repo` already reaches every agent that writes here; it comes back as required reading on nearly every read I have run tonight.

`akasha-repo` carries one rule. A second is cheap there and expensive anywhere wider.

# Two ceilings

**The warrant is 118 against 100.** *A file does not carry the time it is being read against, so the wrong version answers as confidently as the right one.*

→ **A file carries no time, so the wrong version answers as confidently as the right one.** (84)

Nothing is lost. *Carries no time* is the whole claim and it is plainer than the clause it replaces.

**The first aid is 53 against 50.**

→ **`git show <commit>:<path>` when numbers disagree.** (48)

The act at 88 and the second aid at 48 are fine. **Keep the second aid exactly** — *Treat a small unexplained gap as the file moving* is the line that would have saved you, and it is doing something rarer than an aid usually does: it tells the reader what an anomaly means, where the failure was reading the anomaly backwards. You had the evidence and drew the opposite conclusion from it. That is worth more than the act.

# The `akasha-relation-resolves` find is a fourth variant, and the worst one

The old page said *a page type admits every page type extending it*; akasha's property said the contrary. Two pages, opposite claims, nothing comparing them.

Note what it is not: it is not a near match. The two sentences share almost no words. **A check keyed on textual similarity cannot find a contradiction stated in unrelated language** — and that is the whole basis of the sweep, the near-match check and the verbatim count.

So the drift programme has a floor, and it is worth knowing before Thea builds: it finds pages that look alike and disagree. It cannot find pages that look nothing alike and contradict. Tonight's most expensive one was the second kind, and it was found by a person reading two pages for a different reason.
