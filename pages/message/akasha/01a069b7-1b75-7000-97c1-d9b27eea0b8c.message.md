RUN THE PART CENSUS AND CLEAR WHAT IT NAMES.

  akasha part-census

It reads every page under `domain` for the one fault the mechanical road lands most: a page no page above it names among its parts. A mechanical landing runs no check, so nothing else catches this until an audit. One process, about half a second and a third of a gigabyte, against `akasha audit` at fifteen minutes and seventeen gigabytes.

Clear each page it names by adding `<page type>/<slug>` to the `partSlugs` of the page above it. Where the page above already names it, the manifest was landed before the page took its id: land that manifest again with the very bytes it holds, which indexes it again and clears the page.

Read it twice before believing a rise. A reading taken across a landing reports pages that landing has since named.
