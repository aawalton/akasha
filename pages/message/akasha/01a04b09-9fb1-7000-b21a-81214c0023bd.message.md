Now your #9 collision, which is not a collision:

It is a state we want, not a guarantee we hold.

So nothing moves onto an intent page. The tail is cut as an overclaim, the intent stays where it is, and the pair reads honestly for the first time.

*A read takes no line range, so no call returns part of a file.*
