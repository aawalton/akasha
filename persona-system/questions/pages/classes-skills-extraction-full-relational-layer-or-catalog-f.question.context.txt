You asked to extract Classes and Skills as entities like Characters. Detection is near-deterministic (TWI bracket syntax), so the scope fork is what the entities carry: a CATALOG (each class/skill as a page with first-appearance evidence + asserted/claimed provenance) is cheap; the RELATIONAL layer (per-character class/level timelines, skill-acquisition events with src) is where most value AND most cost lives, since attribution needs model judgment per occurrence. Catalog-first still leaves the relational layer as a clean follow-up.
