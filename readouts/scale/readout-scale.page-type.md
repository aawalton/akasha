# Definition

- **Readout scale** — what turns a reading into a color.

# Design

A scale is named by the readouts drawn against it, and belongs to none of them.

A scale's rungs run black, red, orange, yellow, green, blue.

A scale states only the rungs it has.

Rising numbers make a scale ascend, falling ones descend.

Black stands at zero unless a scale moves it.

A scale can award a tier for the act rather than the reading.

An awarded tier never demotes a better rung.

Orange is a rung a stoplight strip cannot draw.
