Slice 4 (editor keyboard conformance) hit the known Mod+Enter collision: Mod+Enter currently collapses a block (a house action), but the standard reserves Ctrl/Cmd+Enter for submit, so collapse must move to a new key (WCAG requires it stay keyboard-operable, so dropping it is off the table). My recommendation: Mod+. (Cmd+. on mac / Ctrl+. on win-linux) -- single modifier, easy reach, collides with nothing else in the editor; only nit is Cmd+. is a legacy macOS Cancel chord, but it's free inside a focused editor and never reaches the OS. Alt: Mod+Shift+. -- safer collision surface but a 3-key chord. Everything else in slice 4 proceeds; only this one rebind waits on your pick.
