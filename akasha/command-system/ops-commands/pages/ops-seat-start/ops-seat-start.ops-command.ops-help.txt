Start a seat. One act: create the seat, bind its name, state what the
seat is, and — where asked — launch it.

`--start-mode` says whether a terminal is attached to the seat as it starts,
which is also what decides who launches it.
  `headless`     none is attached, so this command launches it here,
                 resident in its own supervisor.
  `interactive`  one is attached, so this command starts it DETACHED and
                 prints the id: the caller attaches to the session by
                 name, and attaching is the whole of what it does.
The value is stated on the seat, so the roster knows how it began without
probing for it. `mode` shares this vocabulary and is a different claim: a
seat's mode can change after it starts, and its start mode cannot.

THE PARENT IS NOT STATED. The seat this one answers to is the seat running
this command, read from AGENT_ID in its own environment and from nowhere a
caller can reach: a seat naming a parent it was merely told about reads
exactly like one naming the seat that made it. A seat answering to a person
needs none, that person having started it.

STATE WHAT THE SEAT IS with --persona / --role / --domain. Nothing is read
back out of the name: a name SPELLS what a seat's attributes are, so a seat
is what whoever started it said it is. A slot nobody states takes the stated
persona's own default, and failing that the default that attribute carries.

A PERSONA AND A PERSON GO TOGETHER. A persona is how one person addresses a
seat of their own, so a seat working for the fleet takes the default persona
and the principal `agent`. Either alone is refused before anything is made.

NAMING TAKES NO NAME. A seat's name is composed from what the seat is, and
there is no way to type one beside the attributes: a name SPELLS what a seat
is, so a typed one that disagreed would be a second claim about the same seat.

REFUSES a name any seat already holds, rather than stealing it, and makes
NOTHING on a refusal — the whole decision is taken before the seat exists,
because creating then binding leaves a nameless seat behind every refusal.

Default stdout, `interactive`: the agent id alone, one line.
Default stdout, `headless`:    <agent_id>\t<name>\theadless

--json stdout (stable shape):
  {"agent_id": ..., "name": ..., "start_mode": ..., "pid": ..., "log_path": ...}
