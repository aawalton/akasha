
# Domain abstraction map — The Book of Mormon (Layer 1)

> Domain abstraction map for the Book of Mormon (Layer 1) — the constructed, concept-indexed religion-shape, every claim referenced to the verses that ground it and tagged entailed / inherited-candidate / open. Maintained by the archivist; the synthesis half of the two-artifact tier.

The **constructed, referenced** religion-shape. Built up as the read proceeds.
Each node is an abstraction the text entails; every claim is **referenced** to the
verses that ground it. Indexed by *concept*, not by chapter — the cross-cutting
counterpart to the linear `commentary/`.

This is a **single** concept-indexed file (one `## domain` heading per concept
cluster). It is the deduplicated synthesis the commentary feeds — splitting it by
verse would defeat its purpose. If it grows past the 200-line cap, split it **by
`## domain` section** into a `abstraction-map/` folder beside this file (this file
staying as the legend + routing index), **never by verse**.

## Legend

- **[E]** entailed — the text directly states it, in its own frame. Sub-label the
  *warrant* when it matters: **[E-internal]** = entailed by the text, held on the
  text's own authority (the Layer-1 operation); **[E-external]** = also
  independently established outside the Book of Mormon. Neither is lesser — the
  label tracks which load a claim bears.
- **[I?]** inherited-candidate — believed in the tradition, but check whether the
  text actually entails it or it was carried in from Protestant Christianity.
- **[O]** open — surfaced, not yet resolved.
- Every line ends with its verse refs in `(book c:v)` form. A node accretes refs
  as the read proceeds; contradictions/refinements are noted inline, never
  overwritten.

## Method note

This is the Layer-1 inventory: only what the text *directly* states. Logical
closure / transitivity is Layer 2, a later pass — do not pre-run it here. Each
node is promoted from the commentary by the archivist once it is settled; the
commentary proposes candidate nodes, this file holds the synthesis.
