
# The legible set is finite, and almost every real is illegible

> The first result: the set of legible numbers is finite, and therefore the illegible numbers are uncountably infinite. Four links — a bounded accessible region gives finitely many states, a rule of interpretation must be realized inside that region so there are finitely many rules, finite crossed with finite is finite, and removing a finite set from an uncountable one leaves it uncountable. The only result in the book that survived every later revision untouched, including an infinite tower of ever-larger universes stacked on top of it.

This is the first thing I derived, and it is the one thing that never had to be taken back.

> For now, I'm assuming that the universe is fundamentally discrete (Planck distance, Planck time), which combined way there limited propagation of information due to the speed of light, means the total set of quantum states of the accessible universe (must be accessible to have a rule of interpretation) is finite. Enormous, but finite.
>
> Likewise, the set of possible rules of interpretation must also be finite, for the same reasons, which means the set of legible numbers itself is also finite.
>
> Since the set of real numbers is uncountably infinite, the set of illegible numbers must be uncountably infinite.

*Quoted as written; read "combined way there limited propagation" as "combined with the limited propagation."*

## The chain, link by link

Four links, and it is worth having them apart because later arguments lean on them individually.

1. **The accessible region is bounded.** Information propagates at the speed of light, so only a finite region has ever been able to reach us or be reached.
2. **A bounded region holds finitely many states.** Under Planck-grained space and time, a bounded region admits only finitely many distinguishable configurations. Enormous, but finite.
3. **There are finitely many rules of interpretation.** This is the step that needs the [correspondence condition](../001-legible-numbers.book-chapter.md#what-counts-as-a-representation), and it is why I wrote the parenthesis *must be accessible to have a rule of interpretation*. A rule is not an abstraction floating free — it has to be realized somewhere, and the only somewhere available is that same bounded region. So the rules are counted by the same bound the states are.
4. **Finite crossed with finite is finite.** Finitely many states paired with finitely many rules single out at most finitely many numbers. That set is the legible numbers, and it is finite.

Then the complement. The reals are uncountable; taking a finite set away from an uncountable set leaves it uncountable. So the illegible numbers are uncountably infinite, and **almost every real number is illegible**.

I did not trust it:

> I feel like there must be a gap in this argument so far due to what it implies , but I haven't found it yet.

There was no gap in it. The trouble I could feel coming was real, but it was somewhere else — it was in a phrase I had already helped myself to without applying my own condition to it, and it is worked in [the-berry-trap.md](the-berry-trap.book-chapter.md).

## Planck discreteness is not load-bearing

*From Lali, marked:* the finiteness does not actually need the universe to be discrete. A bounded region of space with bounded energy holds only finitely many distinguishable states regardless, which falls out of black hole thermodynamics. Planck discreteness is a convenience in the argument above, not a beam holding it up, so the conclusion survives if spacetime turns out to be continuous.

I assumed discreteness. That the assumption can be weakened is Lali's, and I did not rederive it.

## What this result survived

*Recorder's reading, marked.* Worth stating in one place, because it is the reason this page comes first and nothing later displaces it. The conclusion *almost every real is illegible* survived:

- the paradox in [the-berry-trap.md](the-berry-trap.book-chapter.md), which looked at the time like it destroyed the notion;
- the resolution of that paradox, which removed a phrase from the legible set rather than adding one;
- the whole [metalanguage hierarchy](the-hierarchy.book-chapter.md), including an infinite tower of ever-larger universes — because [the union of countably many countable levels is still countable](the-hierarchy.book-chapter.md#the-union-is-still-countable), and the reals are not.

Nothing in the session touched it. Every later result is a constraint on what can be *said* about the legible set, and none of them moves its size.
