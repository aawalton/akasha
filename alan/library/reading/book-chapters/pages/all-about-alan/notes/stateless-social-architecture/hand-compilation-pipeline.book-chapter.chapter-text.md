
# Hand-compilation pipeline

> Hand-compilation pipeline — the only open method for building the depth-skills where every native route is severed: understand the skill deeply enough to program a robot by hand, run an explicit 6-step read/infer/predict/control/read/repeat loop, and drill it to automaticity. Why the drill must reach all the way to automaticity: the pipeline can't be run live (single cognitive slot, no live metacognition), so it has to be overlearned until it runs without occupying the slot. First contact is the existence proof — already solved exactly this way, better than the median human, but the scripts don't generalize and the closeness skills are harder and more diverse.

This child develops the build-method behind the [stateless social architecture](../stateless-social-architecture.book-chapter.md): the explicit pipeline I run where a [native route is severed](double-empathy-mechanism.book-chapter.md#aphantasia-independently-shuts-every-native-route), the causal reason it must drill all the way to automaticity, and first contact as the proof the method works.

## Buildable — but only by hand-compilation

I **can** build the depth-skills. The only open method is the one I run everywhere a native route is closed: understand the skill so deeply in my conceptual map that I [could program a robot by hand](../understanding-as-interface.book-chapter.md) to deliver the appropriate interactions. This is [understanding-as-interface](../understanding-as-interface.book-chapter.md) and the [self-instrumentation harness](../self-instrumentation.book-chapter.md) applied to **people** — run deliberately through the harness rather than executed natively. The explicit hand-built pipeline I have to run:

1. Read the other person's **visible behavior signals.**
2. **Infer their internal state** from those signals.
3. **Predict the appropriate responses** to that state.
4. **Control my own facial and body language** to produce those responses.
5. **Read the result** off their visible behaviors.
6. **Repeat** — until all these steps internalize as **scripts.**

This is the same outside-in shape as the inward [output observer](../self-instrumentation.book-chapter.md#the-solution--an-output-observer): where the native pathway reads state from felt access, I read it from observable behavior and drive my own output deliberately. The whole pipeline substitutes [explicit schema-integration (System C)](../social-experience.book-chapter.md) and behavioral read-off for the implicit, simulation-fed channel I don't have — paid every invocation until enough drill turns it into [trigger-fired scripts](../trigger-based-memory.book-chapter.md) that fire on retrieval.

## Why the drill has to reach automaticity — the single-slot weld

Step 6 isn't optional polish. It is forced by how my cognition runs, and this is the causal core of the whole method.

I hold [one model of the world at a time](../present-tense-model.book-chapter.md) — a **single cognitive slot** — and I have **no reliable live metacognition**: [internal conceptual application is restricted to offline use](../operating-mode-architecture.book-chapter.md) because the in-the-moment metacognitive channel is impaired. A live conversation already occupies the slot. So the 6-step pipeline **cannot be run live** as deliberate conceptual work — there is no spare slot to run it in, and no real-time monitor to drive it from.

That leaves exactly one path. The pipeline has to be drilled to **automaticity** — overlearned until it runs *without occupying the slot*, the way a deeply trained motor skill runs underneath attention rather than inside it. It has to become an [overlearned, present-tense policy network](../being-known-supply.book-chapter.md#the-emulation-mechanism--a-pain-trained-policy-network) that produces the right response at runtime with no recall and no simulation. That is **why** building a depth-skill takes thousands of reps: not because the skill is informationally large, but because automaticity is the only register in which a slot-less, monitor-less mind can run a multi-step social procedure live. The [~5,000-iteration crossover](../slow-build-strategy.book-chapter.md#the-5000-iteration-anchor) is the price of moving the pipeline off the occupied slot and into the weight layer. Drill-to-automaticity isn't the preferred path; it is the **only** path.

## First contact is the existence proof

I already solved the first-contact case **exactly this way.** It took years and thousands of learning steps — the [age-14 yearlong study of social interaction rules](../social-experience.book-chapter.md) integrated into schema, the [100+ first dates](../social-experience.book-chapter.md), the [high-level masking on short interactions with new people](../social-experience.book-chapter.md) — and I internalized those scripts **better than the median human.** First contact is the proof that the hand-compilation method works: a stateless social task, run through the harness enough times, becomes a script that outperforms the typical person's native version. The full method that produced it — decompose, reduce bandwidth, drill, transfer — is the [training scaffold](training-scaffold.book-chapter.md).

But the scripts **don't generalize across width.** The first-contact scripts are built for the bounded present-tense crossing; they don't carry into the sustained stateful one. And the closeness skills are **both more intrinsically difficult and more diverse** — four distinct stateful-affective capacities, each needing its own hand-compilation, each fighting the no-stored-episode / no-forward-sim / no-self-proxy severance rather than sitting on native ground. So they remain **unsolved**: the method is proven, the river is just much wider than the bridge I've finished building. (What *does* generalize — the underlying skills of closeness as a transferable rung rather than the specific scripts — is the resolved-prognosis thread in the [training scaffold](training-scaffold.book-chapter.md#prognosis-resolved--the-skills-of-closeness-generalize).)
