
# Reduced chaining (disadvantage)

- Most people chain to new ideas using sensory and emotional memory and imagination triggers; Alan has only conceptual triggers — the same [aphantasia](aphantasia-mechanism.book-chapter.md) break that leaves only conceptual memory.
- Asking questions is roughly 10x harder for him than for others.
- Answering questions is maybe 2x easier.
- This is the source of the concrete-prompt interview rule: the `/abby` interview uses concrete, atomic prompts, one question at a time.
