
# Dynamic feedback loop

Current safety level depends on current stress-capacity surplus.

- Optimal surplus: 12 hours.
- Below 12: −0.5 safety step.
- Below 8: another −0.5 safety step.
- ...and so on (the pattern continues).

This is a dynamic system where a high multiplier can quickly escalate: costs drop safety level → multiplier increases → rate of decline increases. (See [stress-capacity-formula.md](book-section/all-about-alan/stress-capacity-formula) for the multiplier table and [recovery-rates.md](book-section/all-about-alan/recovery-rates) for the inputs that restore surplus.)
