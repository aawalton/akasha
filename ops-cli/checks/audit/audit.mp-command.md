# Definition

- **Audit** — every failure a check finds over the tree as it is.

# Design

A check reached here need not be one the gate runs, the gate weighing a change and this weighing the state.

A check judging its author is set aside, an audit putting no act in front of it to weigh.

A finding is printed rather than refused.
